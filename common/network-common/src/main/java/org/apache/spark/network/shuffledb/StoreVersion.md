# StoreVersion类分析文档

## 类的概述和定义

`StoreVersion`类是Spark网络模块中用于标识本地shuffle状态数据库版本信息的工具类。该类采用语义版本号格式管理数据库的版本兼容性，支持JSON序列化和版本比较功能。

**类定义**：
```java
public class StoreVersion
```

**关键特性**：
- 使用语义版本号（主版本.次版本）管理数据库版本
- 支持Jackson JSON序列化和反序列化
- 提供版本比较和哈希功能
- 定义标准的版本键用于数据库存储

## 构造函数参数说明

### 构造函数
```java
@JsonCreator
public StoreVersion(@JsonProperty("major") int major, @JsonProperty("minor") int minor)
```
**参数说明**：
- `major`: 主版本号，表示不兼容的重大变更
- `minor`: 次版本号，表示向后兼容的功能性变更

**注解说明**：
- `@JsonCreator`: Jackson注解，标记构造函数用于JSON反序列化
- `@JsonProperty`: Jackson注解，指定JSON属性与构造函数参数的映射关系

**设计特点**：
- 使用不可变对象设计，确保版本信息的稳定性
- 支持JSON序列化，便于配置存储和传输
- 提供清晰的版本语义定义

## 使用场景和最佳实践

### 主要使用场景
1. **数据库版本管理**：标识shuffle状态数据库的版本信息
2. **升级兼容性检查**：判断数据库是否需要迁移或升级
3. **配置持久化**：将版本信息存储到数据库配置中
4. **版本比较**：比较不同版本的兼容性和功能差异

### 最佳实践示例

#### 版本信息存储
```java
// 创建版本信息
StoreVersion version = new StoreVersion(1, 2);

// 序列化为JSON存储到数据库
db.put(StoreVersion.KEY, serializeToJson(version));
```

#### 版本兼容性检查
```java
// 从数据库读取版本信息
byte[] versionData = db.get(StoreVersion.KEY);
StoreVersion currentVersion = deserializeFromJson(versionData);

// 检查版本兼容性
if (currentVersion.major != expectedVersion.major) {
    // 需要数据迁移或特殊处理
    handleMajorVersionUpgrade(currentVersion, expectedVersion);
} else if (currentVersion.minor < expectedVersion.minor) {
    // 可以向后兼容升级
    performMinorVersionUpgrade(currentVersion, expectedVersion);
}
```

#### 版本比较
```java
StoreVersion v1 = new StoreVersion(1, 0);
StoreVersion v2 = new StoreVersion(1, 1);

// 使用equals方法比较版本相等性

// 使用哈希值进行快速比较
Set<StoreVersion> versionSet = new HashSet<>();
versionSet.add(v1);
```
