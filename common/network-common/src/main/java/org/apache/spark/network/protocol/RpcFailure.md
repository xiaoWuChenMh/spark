# RpcFailure 类分析文档

## 类的概述和定义

`RpcFailure` 是 Spark 网络协议模块中用于表示 RPC 调用失败的具体响应消息类。该类继承自 `AbstractMessage` 并实现了 `ResponseMessage` 接口，专门用于在 RPC 通信过程中向客户端返回操作失败的错误信息。

该类位于 `org.apache.spark.network.protocol` 包中，使用 `final` 修饰符确保不可被继承，是一个功能完整的 RPC 失败响应消息实现类。该类与 `RpcRequest` 形成完整的请求-响应对，是 Spark RPC 通信错误处理机制的关键组件。

## 构造函数参数说明

### 双参构造函数
```java
public RpcFailure(long requestId, String errorString)
```

#### 参数详细说明
- **requestId**：`long` 类型，请求的唯一标识符，用于与对应的请求消息匹配
- **errorString**：`String` 类型，描述失败原因的错误信息

#### 父类构造函数调用
```java
super(null, false);
```
- **消息体**：设置为 `null`，表示此响应不包含数据体
- **帧包含策略**：设置为 `false`，表示消息体不包含在传输帧中
- **设计意图**：失败响应主要包含错误信息，不需要传输数据体

- **类型**：`long`
- **访问修饰符**：`public final`

- **类型**：`String`
