# TransportCipher 接口分析文档

## 类的概述和定义

`TransportCipher` 是 Spark 网络加密模块中的核心接口定义，为所有传输密码实现提供统一的契约。该接口定义了传输密码的基本操作，包括密钥管理和通道集成功能。

**接口定位**：
- 定义传输密码的统一接口规范
- 提供密钥标识和通道集成的标准方法
- 支持多种加密算法的实现扩展

**接口定义**：
```java
interface TransportCipher
```

**包级可见性**：该接口为包级可见，主要供内部加密模块使用。

## 接口方法定义和说明

### 方法签名和功能

#### `getKeyId() throws GeneralSecurityException`
**功能**：获取传输密码的密钥标识符

**方法签名**：
```java
String getKeyId() throws GeneralSecurityException
```

**返回值**：
- `String`：密钥的唯一标识符，通常为十六进制编码的哈希值

**异常说明**：
- `GeneralSecurityException`：密钥操作失败时抛出

**使用场景**：
- 测试和验证密钥的正确性
- 日志记录和调试信息
- 密钥管理和监控

#### `addToChannel(Channel channel) throws IOException, GeneralSecurityException`
**功能**：将传输密码的处理器添加到 Netty 通道管道中

**方法签名**：
```java
void addToChannel(Channel channel) throws IOException, GeneralSecurityException
```

**参数说明**：
- `channel`：Netty 通道实例，用于添加加密解密处理器

**异常说明**：
- `IOException`：通道操作失败时抛出
- `GeneralSecurityException`：密码初始化失败时抛出

**执行效果**：
- 在通道管道中添加加密处理器和解密处理器
- 确保数据在传输过程中的加密和解密
- 建立安全的通信通道

### 核心方法说明

#### `getKeyId(SecretKeySpec key) throws GeneralSecurityException`
**功能**：使用 HKDF 算法生成密钥的唯一标识符

**方法签名**：
```java
@VisibleForTesting
static String getKeyId(SecretKeySpec key) throws GeneralSecurityException
```

**参数说明**：
- `key`：`SecretKeySpec` 密钥规范对象

**实现逻辑**：
```java
byte[] keyIdBytes = Hkdf.computeHkdf(
    "HmacSha256",           // HKDF 算法
    key.getEncoded(),        // 输入密钥材料
    null,                   // 盐值（可选）
    "keyID".getBytes(StandardCharsets.UTF_8), // 应用信息
    32);                    // 输出长度（32字节）
return Hex.encode(keyIdBytes); // 十六进制编码
```

**技术特点**：
- **HKDF 算法**：使用 HMAC-SHA256 进行密钥派生
- **应用信息绑定**：使用 "keyID" 作为应用特定信息
- **固定长度**：生成 32 字节（256 位）的密钥标识符
- **十六进制编码**：便于显示和比较

**注解说明**：
- `@VisibleForTesting`：表示该方法主要用于测试目的
