# ShuffleIndexRecord 类分析文档

## 类的概述和定义

`ShuffleIndexRecord` 是Spark网络shuffle模块中的一个简单值对象类，专门用于封装shuffle块数据的偏移量和长度信息。该类遵循不可变对象设计原则，提供数据的安全访问。

**主要功能定位**：
- 封装shuffle块数据的文件偏移量信息
- 封装shuffle块数据的长度信息
- 提供不可变的数据访问接口
- 作为索引查询结果的返回值

## 构造函数参数说明

### 唯一构造函数
```java
public ShuffleIndexRecord(long offset, long length)
```

**参数详解**：
- `long offset`：shuffle块数据在文件中的起始偏移量（字节位置）
- `long length`：shuffle块数据的长度（字节数）

**构造函数特点**：
- 直接赋值给final字段，确保对象不可变性
- 无参数验证逻辑，假设调用方提供有效数据
- 简单的数据封装，不包含复杂业务逻辑

## 核心属性分析

### 偏移量属性
```java
private final long offset;
```
**作用**：存储shuffle块数据在文件中的起始位置
**数据类型**：long类型，支持大文件操作
**访问方法**：通过`getOffset()`方法提供只读访问

### 长度属性
```java
private final long length;
```
**作用**：存储shuffle块数据的大小
**数据类型**：long类型，支持大文件操作
**访问方法**：通过`getLength()`方法提供只读访问

## 主要方法分类和说明

### 数据访问方法

#### `getOffset()` 方法
```java
public long getOffset()
```
**功能**：获取shuffle块数据的文件偏移量
**返回值**：long类型的偏移量值
**使用场景**：用于定位shuffle数据在文件中的具体位置

#### `getLength()` 方法
```java
public long getLength()
```
**功能**：获取shuffle块数据的长度
**返回值**：long类型的长度值
**使用场景**：用于确定需要读取的数据量大小

## 设计特点总结

### 1. 不可变对象设计
- 所有字段都是final修饰，确保线程安全
- 构造函数完成后对象状态不可改变
- 避免并发访问的数据一致性问题

### 2. 值对象模式（Value Object）
- 主要作用是封装数据而非行为
- 提供简单的数据访问接口
- 无状态变化，纯数据载体

### 3. 最小化设计原则
- 只包含必要的数据字段
- 不包含复杂的业务逻辑
- 保持类的简洁性和单一职责

### 4. 性能优化考虑
- 使用基本数据类型long，避免对象开销
- 直接字段访问，无复杂计算逻辑
- 轻量级对象创建和垃圾回收

## 配置参数说明

### 数据范围限制
- `offset`：long类型，支持最大2^63-1字节的文件偏移
- `length`：long类型，支持最大2^63-1字节的数据长度

### 内存占用分析
- 每个实例占用约16字节（两个long字段）
- 加上对象头开销，总内存占用约24-32字节
- 适合大量创建和频繁使用的场景
