# SkewedGroupByTest.scala 源码分析

## 类的概述和定义

`SkewedGroupByTest` 是一个Spark示例程序，通过数据量线性增长的方式模拟数据倾斜(Data Skew)场景，测试`groupByKey`操作的性能。该程序采用与`SimpleSkewedGroupByTest`不同的倾斜模拟策略，提供了另一种数据倾斜问题的测试方法。

**程序定位**：这是一个专业的数据倾斜测试工具，主要用于评估Spark在处理不同映射器数据量不均衡时的性能表现。

**核心功能**：
- 生成线性增长的数据量分布
- 模拟映射器间数据量不均衡的倾斜场景
- 测试groupByKey操作在数据倾斜下的性能
- 验证Spark在负载不均衡时的处理能力

## 程序入口参数说明

程序接受四个可选命令行参数：
- `numMappers`：映射器数量，默认为2
- `numKVPairs`：基准键值对数量，默认为1000
- `KeySize`：值（Value）的字节大小，默认为1000
- `numReducers`：归约器数量，默认为映射器数量

### 2. 数据生成逻辑
```scala
val pairs1 = spark.sparkContext.parallelize(0 until numMappers, numMappers).flatMap { p =>
  val ranGen = new Random

  // map output sizes linearly increase from the 1st to the last
  numKVPairs = (1.0 * (p + 1) / numMappers * numKVPairs).toInt

  val arr1 = new Array[(Int, Array[Byte])](numKVPairs)
  for (i <- 0 until numKVPairs) {
    val byteArr = new Array[Byte](valSize)
    ranGen.nextBytes(byteArr)
    arr1(i) = (ranGen.nextInt(Int.MaxValue), byteArr)
  }
  arr1
}.cache()
```

**详细生成过程**：
1. **并行任务**：创建numMappers个并行任务
2. **线性调整**：根据映射器索引线性调整数据量
3. **随机数生成**：每个任务创建独立的Random实例
4. **数据准备**：创建存储键值对的数组
5. **值生成**：生成随机字节数组作为值
6. **键生成**：生成随机整数作为键
7. **数据返回**：返回生成的键值对数组

### 3. 数据量线性增长算法
```scala
numKVPairs = (1.0 * (p + 1) / numMappers * numKVPairs).toInt
```

**线性增长公式**：
- **映射器索引**：p从0到numMappers-1
- **增长因子**：(p + 1) / numMappers
- **数据量调整**：numKVPairs × 增长因子

**具体分布**：
- 第一个映射器（p=0）：数据量 = numKVPairs / numMappers
- 最后一个映射器（p=numMappers-1）：数据量 = numKVPairs
- 中间映射器：数据量线性增长

### 4. 缓存强制计算
```scala
pairs1.count()
```
- 强制Spark计算并缓存数据
- 确保后续操作使用缓存数据
- 为性能测试提供准确的时间基准

### 5. groupByKey操作
```scala
println(pairs1.groupByKey(numReducers).count())
```
- 执行groupByKey操作，指定归约器数量
- 使用count操作触发实际计算
- 输出结果用于性能验证
