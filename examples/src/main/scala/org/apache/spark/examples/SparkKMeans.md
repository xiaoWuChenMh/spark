# SparkKMeans.scala 源码分析

## 类的概述和定义

`SparkKMeans` 是一个Spark示例程序，实现了从文件读取数据的分布式K-means聚类算法。该程序展示了如何在实际生产环境中使用Spark进行无监督学习任务，是Spark机器学习应用中聚类分析的典型示例。

**程序定位**：这是一个生产导向的教学示例，主要用于学习如何在实际环境中使用Spark进行聚类分析。程序明确提示用户在生产环境中应使用Spark MLlib中的标准K-means实现。

**核心功能**：
- 从文件系统读取聚类数据
- 实现分布式K-means聚类算法
- 使用收敛距离判断算法终止条件
- 支持大规模数据集的聚类分析

## 程序入口参数说明

程序接受三个必需命令行参数：
- `file`：数据文件路径，包含待聚类的数据点
- `k`：聚类数量（簇的数量）
- `convergeDist`：收敛距离阈值，控制算法终止条件

## 分布式算法设计特点

### 1. 数据读取与解析
```scala
val lines = spark.read.textFile(args(0)).rdd
val data = lines.map(parseVector _).cache()
```
**数据预处理**：
- **文件读取**：使用Spark的文本文件读取器
- **数据解析**：将每行文本解析为特征向量
- **数据缓存**：缓存解析后的数据提高性能

### 2. 初始中心选择
```scala
val kPoints = data.takeSample(withReplacement = false, K, 42)
```
**初始化策略**：
- **随机采样**：从数据集中随机选择K个点作为初始中心
- **无重复采样**：确保每个初始中心不同
- **固定种子**：使用种子42确保结果可重现

### 3. 聚类分配阶段
```scala
val closest = data.map(p => (closestPoint(p, kPoints), (p, 1)))
```
**分配策略**：
- **并行计算**：每个数据点并行计算最近中心
- **键值对生成**：生成(中心索引, (数据点, 1))键值对
- **统计准备**：为后续统计计算准备数据

### 4. 聚类统计阶段
```scala
val pointStats = closest.reduceByKey(mergeResults)
```
**统计计算**：
- **按中心分组**：使用reduceByKey按中心索引分组
- **统计合并**：使用mergeResults合并每个簇的统计信息
- **向量和计数**：计算每个簇的向量和与数据点数量

### 5. 中心更新阶段
```scala
val newPoints = pointStats.map { pair =>
  (pair._1, pair._2._1 * (1.0 / pair._2._2))
}.collectAsMap()
```
**中心计算**：
- **平均值计算**：将向量和除以数据点数量得到新中心
- **结果收集**：使用collectAsMap收集新中心点
- **映射结构**：构建中心索引到新中心的映射

### 6. 收敛判断
```scala
var tempDist = 0.0
for (i <- 0 until K) {
  tempDist += squaredDistance(kPoints(i), newPoints(i))
}
```
**收敛条件**：
- **距离计算**：计算新旧中心之间的总距离
- **阈值比较**：与convergeDist比较判断是否收敛
- **迭代控制**：控制算法迭代次数
