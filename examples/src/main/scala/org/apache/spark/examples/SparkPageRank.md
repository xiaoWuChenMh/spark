# SparkPageRank.scala 源码分析

## 类的概述和定义

`SparkPageRank` 是一个Spark示例程序，实现了分布式PageRank算法。PageRank是Google搜索引擎的核心算法，用于计算网页的重要性排名，是图算法在分布式环境中的经典应用示例。

**程序定位**：这是一个重要的图算法教学示例，主要用于学习如何在Spark中实现复杂的图算法。程序明确提示用户在生产环境中应使用Spark GraphX中的标准PageRank实现。

**核心功能**：
- 从文件读取网页链接关系数据
- 实现分布式PageRank算法
- 计算网页的重要性排名
- 支持大规模网页图的排名计算

## 程序入口参数说明

程序接受两个可选命令行参数：
- `file`：数据文件路径，包含网页链接关系
- `iter`：PageRank迭代次数，默认为10

## PageRank算法原理分析

### 1. PageRank核心思想
**基本概念**：
- **随机游走模型**：模拟用户在网页间的随机点击行为
- **重要性传递**：重要网页的链接传递更多重要性
- **阻尼因子**：考虑用户随机跳转到任意网页的可能性

**数学公式**：
```
PR(A) = (1-d) + d * (PR(T1)/C(T1) + ... + PR(Tn)/C(Tn))
```
- **PR(A)**：网页A的PageRank值
- **d**：阻尼因子（通常为0.85）
- **PR(Ti)**：指向A的网页Ti的PageRank值
- **C(Ti)**：网页Ti的出链数量

### 2. 算法实现流程
**迭代过程**：
1. **链接关系构建**：建立URL到出链集合的映射
2. **初始排名分配**：所有网页初始排名为1.0
3. **排名传递计算**：每个网页将排名按比例传递给邻居
4. **排名更新**：结合随机跳转概率更新排名
5. **迭代收敛**：重复直到收敛或达到最大迭代次数

## 分布式算法设计特点

### 1. 数据预处理阶段
```scala
val links = lines.map{ s =>
  val parts = s.split("\\s+")
  (parts(0), parts(1))
}.distinct().groupByKey().cache()
```
**预处理流程**：
1. **数据解析**：将每行分割为源URL和目标URL
2. **去重处理**：去除重复的链接关系
3. **分组聚合**：按源URL分组，得到出链集合
4. **数据缓存**：缓存链接关系图提高性能

### 2. 排名传递计算
```scala
val contribs = links.join(ranks).values.flatMap{ case (urls, rank) =>
  val size = urls.size
  urls.map(url => (url, rank / size))
}
```
**贡献计算**：
1. **数据连接**：将链接关系与当前排名连接
2. **贡献分配**：每个网页将排名平均分配给所有出链
3. **扁平映射**：生成(目标URL, 贡献值)键值对

### 3. 排名更新阶段
```scala
ranks = contribs.reduceByKey(_ + _).mapValues(0.15 + 0.85 * _)
```
**排名更新**：
1. **贡献聚合**：按目标URL聚合所有贡献值
2. **阻尼因子应用**：应用PageRank公式更新排名
3. **新排名生成**：生成新的排名向量
