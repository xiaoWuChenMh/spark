# LocalPi.scala 源码分析

## 类的概述和定义

`LocalPi` 是一个Spark示例程序，使用蒙特卡洛(Monte Carlo)方法估算圆周率π的值。这是Spark示例中最简单但最具代表性的程序之一，展示了随机采样方法在数值计算中的应用。

**程序定位**：这是一个算法演示示例，主要用于展示蒙特卡洛方法的基本原理和实现方式。程序简洁明了，适合初学者理解随机采样和概率统计的概念。

**核心功能**：
- 使用蒙特卡洛方法估算π值
- 通过随机点落在单位圆内的概率计算π
- 展示随机采样在数值计算中的应用

## 程序参数配置说明

程序使用固定的参数配置，不接受命令行参数：
- `100000`：随机采样点数量
- 采样范围：[-1, 1] × [-1, 1]的正方形区域
- 目标区域：单位圆（半径1）

## 主要方法分类和说明

### 1. main方法
**功能**：程序主入口，负责完整的蒙特卡洛π估算流程

**执行步骤**：
1. 初始化计数器为0
2. 进行100,000次随机采样
3. 对每个采样点判断是否落在单位圆内
4. 统计落在圆内的点数
5. 计算并输出π的估算值

### 2. 随机点生成逻辑
```scala
val x = random * 2 - 1
val y = random * 2 - 1
```
**坐标转换**：
- **原始范围**：random函数生成[0,1)的随机数
- **缩放变换**：乘以2将范围扩展到[0,2)
- **平移变换**：减去1将范围平移到[-1,1]
- **最终范围**：x和y都在[-1,1]范围内均匀分布

### 3. 圆内判断逻辑
```scala
if (x*x + y*y <= 1) count += 1
```
**几何判断**：
- **距离公式**：使用x² + y²计算点到原点的距离
- **圆内条件**：距离≤1表示点在单位圆内
- **计数更新**：满足条件时计数器加1

### 4. π值计算逻辑
```scala
println(s"Pi is roughly ${4 * count / 100000.0}")
```
**概率公式**：
- **面积比**：圆面积/正方形面积 = π/4
- **概率估计**：落在圆内的点数/总点数 ≈ π/4
- **π估算**：π ≈ 4 × (落在圆内的点数/总点数)

## 算法原理分析

### 1. 蒙特卡洛方法基础
**核心思想**：通过随机采样来估算难以直接计算的数值

**数学原理**：
- 单位圆面积：π
- 外接正方形面积：4
- 面积比：π/4
- 概率估计：P(点落在圆内) ≈ π/4

### 2. π估算公式推导
**估算公式**：
```
π ≈ 4 × (落在圆内的点数 / 总采样点数)
```

**误差分析**：
- **统计误差**：与√N成反比，N为采样点数
- **收敛速度**：O(1/√N)的收敛速度
- **精度提升**：每增加100倍采样点，精度提高10倍

### 3. 随机采样策略
**均匀采样**：
- 在[-1,1]×[-1,1]的正方形内均匀采样
- 确保每个点被选中的概率相等
- 保证估算的无偏性

## 性能优化点分析

### 1. 计算效率优化

## 数学原理深入分析

### 1. 几何概率模型
**样本空间**：正方形区域[-1,1]×[-1,1]，面积=4
**事件空间**：单位圆x²+y²≤1，面积=π
**概率公式**：P(点落在圆内) = π/4

### 2. 大数定律应用
**定律表述**：当试验次数足够多时，频率趋近于概率
**具体应用**：
```
lim(N→∞) count/N = π/4
```
**实际估算**：π ≈ 4 × count/N

### 3. 误差估计理论
**标准误差**：σ = √[π(4-π)/N]
**置信区间**：估算值±1.96σ包含真实值的概率为95%
**实际误差**：对于N=100,000，误差约为0.005
