# HdfsTest.scala 源码分析

## 类的概述和定义

`HdfsTest` 是一个Spark性能测试程序，专门用于测试HDFS文件读取和基本RDD操作的性能。该程序通过读取HDFS文件、缓存数据并进行多次迭代测试来评估Spark的文件I/O和内存操作效率。

**程序定位**：这是一个I/O性能基准测试工具，主要用于评估Spark与HDFS的集成性能和RDD操作效率。

**核心功能**：
- 读取HDFS文本文件
- 测试RDD转换和缓存操作
- 多次迭代性能测试
- 文件内容分析和统计

## 程序入口参数说明

程序接受一个必需命令行参数：
- `file`：HDFS文件路径，必须是存在的文件

## 核心属性分析

### 1. 文件读取配置
```scala
val file = spark.read.text(args(0)).rdd
```
- 使用Spark DataFrame API读取文本文件
- 转换为RDD进行后续操作
- 支持HDFS、本地文件系统等多种文件系统

### 2. 数据缓存配置
```scala
val mapped = file.map(s => s.length).cache()
```
- 对文件内容进行映射转换（计算每行长度）
- 使用`.cache()`方法缓存转换结果
- 避免重复计算，提高性能测试准确性

### 3. 时间测量配置
```scala
val startTimeNs = System.nanoTime()
val durationMs = TimeUnit.NANOSECONDS.toMillis(System.nanoTime() - startTimeNs)
```
- 使用纳秒级时间戳提高测量精度
- 转换为毫秒便于阅读和分析

### 3. 性能测试循环
```scala
for (iter <- 1 to 10) {
  val startTimeNs = System.nanoTime()
  for (x <- mapped) { x + 2 }

  println(s"Iteration $iter took $durationMs ms")
}
```

**详细流程**：
1. **10次迭代**：进行10次重复测试
2. **时间测量**：使用纳秒级时间戳
3. **操作执行**：遍历缓存数据并执行简单计算
4. **结果输出**：打印每次迭代的执行时间
