# LocalFileLR.scala 源码分析

## 类的概述和定义

`LocalFileLR` 是一个Spark示例程序，实现了逻辑回归(Logistic Regression)分类算法。该程序使用本地文件作为数据源，通过梯度下降法优化模型参数，是一个典型的机器学习算法教学示例。

**程序定位**：这是一个教学示例，主要用于学习逻辑回归算法的基本原理和实现方式。程序明确提示用户在实际生产环境中应使用Spark MLlib中的标准逻辑回归实现。

**核心功能**：
- 从本地文件读取训练数据
- 实现逻辑回归模型训练
- 使用梯度下降法优化参数
- 输出模型参数和训练过程

## 程序入口参数说明

程序接受两个必需命令行参数：
- `dataFile`：训练数据文件路径
- `iterations`：梯度下降迭代次数

## 算法原理分析

### 1. 逻辑回归模型
**假设函数**：
```
h(x) = 1 / (1 + exp(-w^T x))
```

**损失函数**（对数似然损失）：
```
L(w) = -∑[y_i log(h(x_i)) + (1-y_i)log(1-h(x_i))]
```

### 2. 梯度计算推导
**梯度公式**：
```
∇L(w) = ∑(h(x_i) - y_i) x_i
```

**代码实现对应**：
```scala
val scale = (1 / (1 + math.exp(-p.y * (w.dot(p.x)))) - 1) * p.y
```
- 对应梯度计算中的`(h(x_i) - y_i)`项
- 考虑了标签y的符号（支持±1标签）

### 3. 优化策略
- **批量梯度下降**：每次迭代使用全部数据
- **固定学习率**：隐含学习率为1（w -= gradient）
- **迭代优化**：通过多次迭代逼近最优解
