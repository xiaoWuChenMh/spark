# AutoCleanupLiveUIDirSuite 测试套件分析文档

## 类的概述和定义

`AutoCleanupLiveUIDirSuite` 是 Apache Spark 中用于测试实时UI目录自动清理功能的测试套件，继承自 `SparkFunSuite`。该类主要验证SparkContext停止后，实时UI存储路径的自动清理机制是否正常工作。

**类定义：**
```scala
class AutoCleanupLiveUIDirSuite extends SparkFunSuite
```

**包路径：** `org.apache.spark.status`

**对应JIRA问题：** SPARK-41694

## 核心测试方法分析

### `test("SPARK-41694: Auto cleanup Spark UI store path")` 方法

**功能：** 验证Spark UI存储路径的自动清理功能

**测试目标：** 确保SparkContext停止后，UI相关临时目录能够被正确清理，避免磁盘空间泄漏

## 测试执行流程分析

### 1. 测试环境准备阶段

#### 临时目录创建
```scala
val baseUIDir = Utils.createTempDir()
```
**功能：** 创建基础UI目录作为测试环境
**技术实现：** 使用Spark的Utils工具类创建临时目录
**目录特性：** 自动设置删除标记，确保测试后清理

#### Spark配置设置
```scala
val conf = new SparkConf()
  .setAppName("ui-dir-cleanup")
  .setMaster("local")
  .set(LIVE_UI_LOCAL_STORE_DIR, baseUIDir.getCanonicalPath)
```

**配置参数说明：**
- **`AppName`**: 设置应用名称为"ui-dir-cleanup"
- **`Master`**: 使用本地模式运行
- **`LIVE_UI_LOCAL_STORE_DIR`**: 关键配置，设置实时UI本地存储目录路径

### 2. SparkContext生命周期测试

#### SparkContext创建和作业执行
```scala
val sc = new SparkContext(conf)
sc.parallelize(0 until 100, 10)
  .map { x => (x % 10) -> x }
  .reduceByKey { _ + _ }
  .collect()
```

**作业设计：**
- **数据规模：** 100个元素，分成10个分区
- **转换操作：** map操作将数据转换为键值对
- **聚合操作：** reduceByKey进行键值聚合
- **触发执行：** collect操作触发实际计算

**目的：** 确保SparkContext正常启动并执行作业，生成UI监控数据

### 3. 运行中状态验证

#### 目录存在性验证
```scala
assert(baseUIDir.exists())
val subDirs = baseUIDir.listFiles()
assert(subDirs.nonEmpty)
```

**验证点：**
- 基础目录必须存在
- 基础目录下必须有子目录
- 确保UI数据正在被写入

#### UI目录结构验证
```scala
val uiDirs = subDirs.filter(_.getName.startsWith("spark-ui"))
assert(uiDirs.length == 1)
assert(uiDirs.head.listFiles().nonEmpty)
```

**目录结构要求：**
- **命名模式：** 子目录名称以"spark-ui"开头
- **唯一性：** 只能存在一个UI目录
- **内容非空：** UI目录必须包含文件，证明数据写入正常

### 4. SparkContext停止后验证

#### 停止SparkContext
```scala
sc.stop()
```

**关键操作：** 触发自动清理机制的执行

#### 清理后状态验证
```scala
assert(baseUIDir.exists())
assert(!uiDirs.head.exists())
assert(baseUIDir.listFiles().isEmpty)
```

**清理效果验证：**
- **基础目录保留：** 基础目录仍然存在
- **UI目录删除：** 具体的UI目录被正确删除
- **目录清空：** 基础目录下所有文件被清理

### 5. 最终资源清理

#### 测试后清理
```scala
finally {
  JavaUtils.deleteRecursively(baseUIDir)
  assert(!baseUIDir.exists())
}
```

**资源管理：**
- **finally块：** 确保在任何情况下都会执行清理
- **递归删除：** 使用JavaUtils工具类彻底删除目录
- **存在性验证：** 确认目录已被完全删除
