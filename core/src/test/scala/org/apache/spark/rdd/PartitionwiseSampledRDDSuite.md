# PartitionwiseSampledRDDSuite 测试类分析

## 类的概述和定义

`PartitionwiseSampledRDDSuite` 是Spark RDD模块中的一个测试类，专门用于测试分区采样RDD（PartitionwiseSampledRDD）的功能特性。该类继承自`SparkFunSuite`并混入`SharedSparkContext`特质，主要验证分区采样RDD的种子分布机制和并发处理能力。

**类定义：**
```scala
class PartitionwiseSampledRDDSuite extends SparkFunSuite with SharedSparkContext
```

## 主要方法分类和说明

### 1. 种子分布测试

#### test("seed distribution")
- **测试目标**：验证分区采样RDD的种子分布机制
- **测试场景**：确保不同分区使用不同的随机种子

##### RDD创建过程：
```scala
val rdd = sc.makeRDD(Array(1L, 2L, 3L, 4L), 2)
```
- **数据内容**：包含4个长整型元素的数组
- **分区数**：2个分区
- **数据分布**：每个分区包含2个元素

##### 采样器创建：
```scala
val sampler = new MockSampler
```
- **采样器类型**：自定义的MockSampler
- **功能特性**：输出设置的种子值用于验证

##### 分区采样RDD创建：
```scala
val sample = new PartitionwiseSampledRDD[Long, Long](rdd, sampler, false, 0L)
```
- **参数说明**：
  - `rdd`：原始RDD
  - `sampler`：采样器实例
  - `false`：是否保留分区器（不保留）
  - `0L`：初始种子值

##### 验证逻辑：
```scala
assert(sample.distinct().count == 2, "Seeds must be different.")
```
- **验证方法**：使用`distinct().count`统计唯一值数量
- **预期结果**：应该有2个不同的种子值
- **验证点**：每个分区使用不同的随机种子

### 2. 并发性测试

#### test("concurrency")
- **测试目标**：验证分区采样RDD的并发处理能力
- **问题背景**：SPARK-2251 Bug修复验证
- **测试场景**：RDD与自身进行zip操作时计算每个分区两次

##### RDD创建过程：
```scala
val rdd = sc.parallelize(0 until 111, 10)
```
- **数据范围**：0到110的整数序列
- **分区数**：10个分区
- **数据规模**：111个元素

##### 采样器测试：
```scala
for (sampler <- Seq(new BernoulliSampler[Int](0.5), new PoissonSampler[Int](0.5))) {
```
- **采样器类型**：
  - `BernoulliSampler`：伯努利采样器，采样率0.5
  - `PoissonSampler`：泊松采样器，采样率0.5
- **测试范围**：覆盖两种常用的采样算法

##### 分区采样RDD创建：
```scala
val sampled = new PartitionwiseSampledRDD[Int, Int](rdd, sampler, true)
```
- **参数说明**：
  - `rdd`：原始RDD
  - `sampler`：采样器实例
  - `true`：保留分区器

##### 并发操作测试：
```scala
sampled.zip(sampled).count()
```
- **操作类型**：RDD与自身进行zip操作
- **并发场景**：每个分区被计算两次
- **验证点**：确保没有并发问题，操作正常完成
