# ExecutorFailuresInTaskSet 类分析

## 类的概述和定义

`ExecutorFailuresInTaskSet` 是 Spark 调度器模块中的一个辅助类，专门用于跟踪在单个任务集（TaskSet）中特定执行器（Executor）上的任务失败情况。该类主要用于排除（exclusion）目的，帮助系统识别和隔离有问题的执行器。

**类定义：**
```scala
private[scheduler] class ExecutorFailuresInTaskSet(val node: String)
```

**主要特性：**
- 私有访问权限，仅在 scheduler 包内可见
- 专注于单个执行器在单个任务集中的失败跟踪
- 提供详细的失败统计和时间信息
- 支持任务级别的失败分析

## 构造函数参数说明

**主要参数：**
- `node: String` - 执行器所在节点的标识符
  - 用于唯一标识被跟踪的执行器
  - 在集群环境中区分不同的计算节点

## 核心属性分析

### 1. 任务失败跟踪映射
```scala
val taskToFailureCountAndFailureTime = HashMap[Int, (Int, Long)]()
```

**数据结构说明：**
- **键（Key）**: `Int` - 任务在任务集中的索引
- **值（Value）**: `(Int, Long)` - 元组包含失败次数和最近失败时间

**设计特点：**
- 使用可变 HashMap 支持动态更新
- 索引化的任务标识便于快速查找
- 时间戳记录支持时间相关的分析

## 主要方法分类和说明

### 1. 失败记录更新方法

#### `updateWithFailure(taskIndex: Int, failureTime: Long): Unit`

**功能：** 更新指定任务的失败记录

**参数说明：**
- `taskIndex: Int` - 任务索引
- `failureTime: Long` - 失败时间戳

**实现逻辑：**
1. 获取现有失败记录（默认为0次失败，-1L时间）
2. 更新失败次数（+1）
3. 更新最近失败时间（取最大值，防止时钟非单调性）
4. 保存更新后的记录

**设计考虑：**
- 防御性编程：处理时钟非单调性问题
- 原子性操作：确保数据一致性

### 2. 统计查询方法

#### `numUniqueTasksWithFailures: Int`

**功能：** 返回有失败记录的唯一任务数量

**实现：** 直接返回映射表的大小

**用途：** 评估执行器的问题范围

#### `getNumTaskFailures(index: Int): Int`

**功能：** 返回指定任务的失败次数

**参数：** `index: Int` - 任务索引

**实现：** 从映射表获取失败次数，默认返回0

**用途：** 特定任务的失败频率分析

### 3. 调试支持方法

#### `override def toString(): String`

**功能：** 提供类的字符串表示，便于调试

**输出格式：**
```
numUniqueTasksWithFailures = X; tasksToFailureCount = {映射内容}
```

**价值：** 日志记录和问题诊断
