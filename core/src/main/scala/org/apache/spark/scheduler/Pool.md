# Pool 类分析

## 类的概述和定义

`Pool` 是 Spark 调度器模块中的核心组件，实现了 `Schedulable` 接口，用于表示可调度实体的集合。该类支持层次化的调度结构，可以包含其他 `Pool` 或 `TaskSetManager`，为 Spark 的公平调度（Fair Scheduler）和 FIFO 调度提供了基础架构支持。

**类定义：**
```scala
private[spark] class Pool(
    val poolName: String,
    val schedulingMode: SchedulingMode,
    initMinShare: Int,
    initWeight: Int)
  extends Schedulable with Logging
```

**主要特性：**
- 私有访问权限，仅在 spark 包内可见
- 继承 Schedulable 接口，支持调度操作
- 集成日志记录功能
- 支持多种调度模式和算法

## 构造函数参数说明

**主要参数：**
- `poolName: String` - 调度池的名称标识符
- `schedulingMode: SchedulingMode` - 调度模式（FAIR 或 FIFO）
- `initMinShare: Int` - 池的最小资源份额配置
- `initWeight: Int` - 池的权重配置，影响资源分配比例

**参数设计意图：**
- **名称标识**：支持多池管理和识别
- **模式选择**：支持不同的调度策略
- **资源控制**：通过最小份额和权重实现精细的资源分配

## 核心属性分析

### 1. 调度队列管理属性

#### `val schedulableQueue = new ConcurrentLinkedQueue[Schedulable]()`

**功能：** 存储可调度实体的队列

**设计特点：**
- **线程安全**：使用 ConcurrentLinkedQueue 支持并发访问
- **FIFO 顺序**：保持添加顺序，便于调度算法处理
- **动态管理**：支持实时的添加和移除操作

#### `val schedulableNameToSchedulable = new ConcurrentHashMap[String, Schedulable]()`

**功能：** 名称到可调度实体的映射

**设计特点：**
- **快速查找**：支持 O(1) 复杂度的名称查找
- **线程安全**：ConcurrentHashMap 保证并发安全
- **索引优化**：为名称查询提供快速访问路径

### 2. 资源分配属性

#### `val weight = initWeight`

**功能：** 池的权重，影响资源分配比例

**作用：**
- **比例分配**：权重高的池获得更多资源
- **公平调度**：在公平调度模式下决定资源分配
- **优先级控制**：实现不同池之间的优先级差异

#### `val minShare = initMinShare`

**功能：** 池的最小资源份额

**作用：**
- **资源保障**：确保池获得最低限度的资源
- **饥饿避免**：防止低优先级池完全无法获得资源
- **公平性保证**：在资源紧张时保证基本运行需求

### 3. 运行状态属性

#### `var runningTasks = 0`

**功能：** 当前运行的 task 数量

**设计特点：**
- **动态跟踪**：实时更新运行任务数量
- **资源监控**：反映池的当前负载状态
- **调度决策**：影响后续任务的调度决策

#### `val priority = 0`

**功能：** 池的优先级（当前固定为0）

**设计意图：**
- **预留扩展**：为未来优先级调度预留接口
- **当前简化**：当前实现中优先级概念未充分使用

### 4. 层次结构属性

#### `var stageId = -1`

**功能：** 用于调度决策的 tie-breaking 标识

**作用：**
- **冲突解决**：在调度决策平局时提供依据
- **阶段关联**：与特定阶段关联，支持阶段级调度

#### `val name = poolName`

**功能：** 池的唯一名称标识

**设计特点：**
- **唯一性**：确保池的标识唯一
- **查找支持**：便于在层次结构中定位池

#### `var parent: Pool = null`

**功能：** 父池引用，支持层次化结构

**作用：**
- **层次构建**：形成树状的调度层次结构
- **状态传播**：支持运行任务数量的向上传播
- **资源聚合**：实现层次化的资源管理

### 5. 调度算法属性

#### `private val taskSetSchedulingAlgorithm: SchedulingAlgorithm`

**功能：** 基于调度模式选择的调度算法实例

**算法选择逻辑：**
```scala
schedulingMode match {
  case SchedulingMode.FAIR => new FairSchedulingAlgorithm()
  case SchedulingMode.FIFO => new FIFOSchedulingAlgorithm()
  case _ => throw new IllegalArgumentException(...)
}
```

**设计特点：**
- **策略模式**：根据配置动态选择算法
- **算法隔离**：不同调度算法的实现分离
- **扩展支持**：便于添加新的调度算法

## 主要方法分类和说明

### 1. 可调度实体管理方法

#### `override def addSchedulable(schedulable: Schedulable): Unit`

**功能：** 添加可调度实体到池中

**实现逻辑：**
1. **参数验证**：确保 schedulable 不为 null
2. **队列添加**：添加到 schedulableQueue
3. **映射更新**：更新名称到实体的映射
4. **父级设置**：设置实体的父池引用

**设计特点：**
- **完整性保证**：确保所有相关数据结构同步更新
- **层次维护**：维护正确的父子关系
- **线程安全**：使用线程安全的数据结构

#### `override def removeSchedulable(schedulable: Schedulable): Unit`

**功能：** 从池中移除可调度实体

**实现逻辑：**
```scala
schedulableQueue.remove(schedulable)
schedulableNameToSchedulable.remove(schedulable.name)
```

**设计特点：**
- **同步移除**：确保队列和映射的同步更新
- **资源清理**：及时释放不再需要的资源
- **状态维护**：保持池的状态一致性

#### `override def getSchedulableByName(schedulableName: String): Schedulable`

**功能：** 根据名称查找可调度实体

**查找策略：**
1. **直接查找**：首先在映射中直接查找
2. **递归查找**：如果未找到，递归搜索子池
3. **返回结果**：找到返回实体，否则返回 null

**设计特点：**
- **性能优化**：优先使用 O(1) 的映射查找
- **深度搜索**：支持层次结构的深度搜索
- **空值安全**：使用 null 表示未找到

### 2. 执行器管理方法

#### `override def executorLost(executorId: String, host: String, reason: ExecutorLossReason): Unit`

**功能：** 处理执行器丢失事件

**实现逻辑：**
```scala
schedulableQueue.asScala.foreach(_.executorLost(executorId, host, reason))
```

**设计特点：**
- **事件传播**：将事件传播给所有子实体
- **统一处理**：确保所有实体得到通知
- **故障恢复**：支持执行器故障的恢复处理

#### `override def executorDecommission(executorId: String): Unit`

**功能：** 处理执行器停用事件

**实现逻辑：**
```scala
schedulableQueue.asScala.foreach(_.executorDecommission(executorId))
```

**设计特点：**
- **停用通知**：通知所有子实体执行器停用
- **资源回收**：支持优雅的资源回收过程
- **计划维护**：处理计划性的执行器下线

### 3. 任务调度方法

#### `override def checkSpeculatableTasks(minTimeToSpeculation: Long): Boolean`

**功能：** 检查是否需要启动推测执行

**实现逻辑：**
1. **遍历检查**：检查所有子实体是否需要推测执行
2. **结果聚合**：使用逻辑或操作聚合结果
3. **返回决策**：返回是否需要启动推测执行

**设计特点：**
- **分布式决策**：每个实体独立判断
- **结果聚合**：任一实体需要即返回 true
- **性能优化**：避免不必要的推测执行

#### `override def getSortedTaskSetQueue: ArrayBuffer[TaskSetManager]`

**功能：** 获取排序后的任务集队列

**排序流程：**
1. **实体排序**：使用调度算法对可调度实体排序
2. **任务集收集**：从每个实体收集可调度的任务集
3. **结果返回**：返回排序后的任务集列表

**算法应用：**
```scala
val sortedSchedulableQueue = schedulableQueue.asScala.toSeq.sortWith(taskSetSchedulingAlgorithm.comparator)
```

**设计特点：**
- **算法抽象**：使用统一的比较器接口
- **模式适配**：支持不同调度模式的排序
- **过滤条件**：只返回可调度的任务集
