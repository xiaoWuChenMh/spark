# BlockManagerSource.scala 源码分析

## 类的概述和定义

`BlockManagerSource.scala` 是Spark存储系统中负责监控指标收集的核心组件，它实现了`Source`接口，通过Codahale Metrics库为块管理器提供全面的性能监控和指标收集功能。该组件是Spark监控体系的重要组成部分，为系统运维和性能调优提供关键数据支持。

**核心架构：**
- `BlockManagerSource`：主监控类，继承Source接口
- `MetricRegistry`：Codahale Metrics注册表，管理所有指标
- `Gauge`：指标收集器，提供实时数据采集

**监控范围：**
- **内存使用**：堆内/堆外内存分配和使用情况
- **磁盘使用**：磁盘空间使用情况
- **容量监控**：最大容量和剩余容量监控

## 构造函数参数说明

### BlockManagerSource类参数
- `blockManager: BlockManager` - 块管理器实例，提供状态数据源

### 继承属性
- `metricRegistry: MetricRegistry` - 指标注册表（继承自Source接口）
- `sourceName: String = "BlockManager"` - 监控源名称（继承自Source接口）

## 核心属性分析

### 1. 指标注册表（MetricRegistry）

#### 注册表管理
- **统一管理**：所有监控指标统一注册到MetricRegistry
- **命名空间**：使用MetricRegistry.name()方法生成标准化的指标名称
- **生命周期**：与BlockManagerSource实例生命周期一致

#### 指标命名规范
- **层级命名**：使用点分隔的层级命名（如"memory.maxMem_MB"）
- **单位标识**：指标名称包含单位信息（_MB）
- **分类清晰**：按功能分类（memory、disk等）

### 2. 监控源标识

#### sourceName属性
- **固定值**："BlockManager"，标识监控源类型
- **监控集成**：便于监控系统识别和聚合数据
- **命名空间**：在全局监控体系中唯一标识

## 主要方法分类和说明

### 1. 指标注册方法

#### registerGauge方法
- **功能**：统一注册Gauge类型指标
- **参数**：
  - `name: String` - 指标名称
  - `func: BlockManagerMaster => Long` - 数据获取函数
- **单位转换**：自动将字节转换为MB单位

#### 方法实现
```scala
private def registerGauge(name: String, func: BlockManagerMaster => Long): Unit = {
  metricRegistry.register(name, new Gauge[Long] {
    override def getValue: Long = func(blockManager.master) / 1024 / 1024
  })
}
```

**设计特点：**
- **函数式参数**：使用函数参数提高灵活性
- **自动转换**：字节到MB的自动单位转换
- **统一接口**：所有指标使用相同的注册接口

### 2. 内存监控指标

#### 容量监控指标
- `memory.maxMem_MB` - 总内存容量（MB）
- `memory.maxOnHeapMem_MB` - 堆内内存容量（MB）
- `memory.maxOffHeapMem_MB` - 堆外内存容量（MB）

#### 使用情况监控指标
- `memory.memUsed_MB` - 总内存使用量（MB）
- `memory.onHeapMemUsed_MB` - 堆内内存使用量（MB）
- `memory.offHeapMemUsed_MB` - 堆外内存使用量（MB）

#### 剩余容量监控指标
- `memory.remainingMem_MB` - 总剩余内存（MB）
- `memory.remainingOnHeapMem_MB` - 堆内剩余内存（MB）
- `memory.remainingOffHeapMem_MB` - 堆外剩余内存（MB）

### 3. 磁盘监控指标

#### 磁盘使用指标
- `disk.diskSpaceUsed_MB` - 磁盘空间使用量（MB）
