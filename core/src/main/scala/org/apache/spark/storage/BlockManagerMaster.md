# BlockManagerMaster.scala 源码分析

## 类的概述和定义

`BlockManagerMaster.scala` 是Spark存储系统中块管理器主控节点的核心组件，负责协调和管理集群中所有块管理器的状态和操作。它作为Driver端的中央协调器，提供块注册、状态查询、块移除等关键功能。

**核心架构：**
- `BlockManagerMaster`：主管理类，提供所有块管理操作的接口
- `BlockManagerMaster`伴生对象：定义端点名称常量
- RPC通信：通过Driver端点与集群中其他节点通信

## 构造函数参数说明

### BlockManagerMaster类参数
- `driverEndpoint: RpcEndpointRef` - Driver端RPC端点引用，用于与Driver通信
- `driverHeartbeatEndPoint: RpcEndpointRef` - Driver心跳端点引用，用于心跳检测
- `conf: SparkConf` - Spark配置对象
- `isDriver: Boolean` - 标识当前节点是否为Driver节点

### 内部属性
- `timeout` - RPC调用超时时间，从配置中获取
- 端点引用为var类型，支持动态更新

## 核心属性分析

### RPC端点管理
- `driverEndpoint` - 主通信端点，处理所有块管理操作
- `driverHeartbeatEndPoint` - 心跳端点，用于健康检测
- **端点复用**：两个端点分别处理不同功能，避免单点瓶颈

### 配置相关属性
- `timeout` - 动态从配置获取RPC超时时间
- `isDriver` - 标识节点角色，影响某些操作的行为

### 状态管理属性
- 无显式状态存储，状态通过Driver端点维护
- **去中心化设计**：状态分散在Driver和Executor节点

## 主要方法分类和说明

### 1. 节点生命周期管理方法

#### registerBlockManager()
- **功能**：注册块管理器到Driver
- **参数**：包含本地目录、内存大小、存储端点等完整信息
- **返回值**：更新后的BlockManagerId（包含拓扑信息）
- **重注册支持**：支持isReRegister参数处理重注册场景

#### removeExecutor() / removeExecutorAsync()
- **功能**：移除失效的Executor
- **同步/异步**：提供同步和异步两种移除方式
- **清理策略**：彻底清理失效节点的相关状态

#### decommissionBlockManagers()
- **功能**：退役指定的块管理器
- **非阻塞**：异步执行，不阻塞调用线程
- **批量处理**：支持同时退役多个Executor

### 2. 块信息查询方法

#### getLocations() / getLocationsAndStatus()
- **功能**：查询块的存储位置和状态
- **多版本**：支持获取位置列表和详细状态信息
- **批量查询**：getLocations(Array[BlockId])支持批量查询

#### getReplicateInfoForRDDBlocks()
- **功能**：获取RDD块的复制信息
- **用途**：用于块退役时的数据迁移
- **粒度**：按块管理器获取所有RDD块信息

#### getPeers()
- **功能**：获取集群中的对等节点列表
- **拓扑感知**：考虑网络拓扑信息选择对等节点
- **负载均衡**：用于数据复制时的节点选择

### 3. 块状态更新方法

#### updateBlockInfo()
- **功能**：更新块的存储信息
- **参数**：包含存储级别、内存大小、磁盘大小等
- **同步操作**：确保状态一致性

#### getMemoryStatus() / getStorageStatus()
- **功能**：获取集群内存和存储状态
- **监控支持**：为资源监控和调度提供数据
- **聚合视图**：提供集群级别的聚合信息

### 4. 块移除操作方法

#### removeBlock()
- **功能**：移除指定的块
- **同步操作**：等待移除完成
- **错误处理**：处理移除失败的情况

#### removeRdd() / removeShuffle() / removeBroadcast()
- **功能**：按类型批量移除块
- **异步支持**：支持阻塞和非阻塞两种模式
- **资源清理**：彻底清理相关资源

### 5. 高级查询方法

#### getBlockStatus()
- **功能**：获取块的详细状态信息
- **异步查询**：使用Future避免死锁
- **性能考虑**：标记为测试用途，避免生产环境使用

#### getMatchingBlockIds()
- **功能**：根据过滤器获取匹配的块ID
- **灵活查询**：支持自定义过滤条件
- **性能警告**：明确标记为潜在昂贵操作
