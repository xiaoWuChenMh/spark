# SamplingUtils 类分析文档

## 类的概述和定义

`SamplingUtils` 是Spark内部使用的一个采样工具类，提供了多种采样算法和统计计算功能。该类被标记为`private[spark]`，是Spark内部使用的统计采样工具。

该类包含三个主要组件：
- `SamplingUtils` 对象：主要的采样方法实现
- `PoissonBounds` 对象：泊松分布边界计算工具
- `BinomialBounds` 对象：二项分布边界计算工具

## 构造函数参数说明

由于`SamplingUtils`是一个工具类对象（object），没有构造函数参数。

## 核心属性分析

### BinomialBounds.minSamplingRate
- **类型**: `Double`
- **值**: `1e-10`
- **作用**: 定义最小采样率，避免随机数生成器的精度限制问题
- **访问权限**: `private[spark]`

## 主要方法分类和说明

### 采样方法

#### `reservoirSampleAndCount[T: ClassTag]`
- **功能**: 实现水库采样算法，同时返回样本和输入大小
- **参数**:
  - `input: Iterator[T]` - 输入数据迭代器
  - `k: Int` - 水库大小（样本容量）
  - `seed: Long = Random.nextLong()` - 随机种子（可选）
- **返回值**: `(Array[T], Long)` - 样本数组和输入数据总数
- **算法流程**:
  1. 将前k个元素放入水库
  2. 如果输入数据少于k个，返回修剪后的数组
  3. 如果输入数据多于k个，使用替换策略继续采样
  4. 使用XORShiftRandom生成随机数进行概率替换

#### `computeFractionForSampleSize`
- **功能**: 计算保证样本大小的采样率
- **参数**:
  - `sampleSizeLowerBound: Int` - 最小样本大小
  - `total: Long` - 数据总数
  - `withReplacement: Boolean` - 是否使用有放回采样
- **返回值**: `Double` - 计算得到的采样率
- **算法选择**:
  - 有放回采样：使用泊松分布边界计算
  - 无放回采样：使用二项分布边界计算

### 统计边界计算方法

#### PoissonBounds.getLowerBound
- **功能**: 计算泊松分布的下界λ值
- **参数**: `s: Double` - 样本大小
- **返回值**: `Double` - 下界λ值
- **公式**: `max(s - numStd(s) * sqrt(s), 1e-15)`

#### PoissonBounds.getUpperBound
- **功能**: 计算泊松分布的上界λ值
- **参数**: `s: Double` - 样本大小
- **返回值**: `Double` - 上界λ值
- **公式**: `max(s + numStd(s) * sqrt(s), 1e-10)`

#### BinomialBounds.getLowerBound
- **功能**: 计算二项分布的下界概率p
- **参数**:
  - `delta: Double` - 置信水平
  - `n: Long` - 试验次数
  - `fraction: Double` - 期望的成功比例
- **返回值**: `Double` - 下界概率p

#### BinomialBounds.getUpperBound
- **功能**: 计算二项分布的上界概率p
- **参数**:
  - `delta: Double` - 置信水平
  - `n: Long` - 试验次数
  - `fraction: Double` - 期望的成功比例
- **返回值**: `Double` - 上界概率p

### 辅助方法

#### PoissonBounds.numStd
- **功能**: 根据样本大小确定标准差倍数
- **参数**: `s: Double` - 样本大小
- **返回值**: `Double` - 标准差倍数
- **策略**: 小样本使用较大倍数，大样本使用较小倍数

## 设计特点总结

### 1. 算法多样性
- 支持水库采样算法
- 提供有放回和无放回采样的概率计算
- 基于不同的统计分布进行边界估计

### 2. 统计严谨性
- 使用泊松分布和二项分布进行概率计算
- 提供99.99%置信水平的采样率保证
- 考虑随机数生成器的精度限制

### 3. 性能优化
- 使用高效的XORShiftRandom随机数生成器
- 针对不同样本大小采用不同的标准差策略
- 避免不必要的数学计算

### 4. 类型安全
- 使用泛型支持任意数据类型
- 编译时类型检查
- 支持ClassTag用于运行时类型信息

## 配置参数说明

### 随机种子配置
- **参数**: `seed: Long`
- **默认值**: `Random.nextLong()`
- **作用**: 控制随机数生成的可重复性

### 置信水平配置
- **参数**: `delta: Double`
- **默认值**: `1e-4`（对应99.99%置信水平）
- **作用**: 控制采样成功率的统计保证

### 精度限制配置
- **最小采样率**: `1e-10`
- **最小λ值**: `1e-15`
- **作用**: 避免数值计算中的精度问题

## 性能优化点分析

### 优势
- **内存效率**: 水库采样只需要O(k)的内存空间
- **计算效率**: 单次遍历即可完成采样
- **随机数效率**: 使用高效的XORShiftRandom算法

### 潜在考虑
- **随机数质量**: 依赖XORShiftRandom的随机性质量
- **数值稳定性**: 在极端情况下可能存在数值精度问题
- **并发安全**: 方法本身是线程安全的，但随机数生成器需要关注

## 异常处理机制

### 输入验证
- 对输入参数进行合理性检查
- 处理边界情况（如输入数据少于水库大小）
- 避免除零错误和数值溢出

### 数值安全
- 使用math.max确保数值下限
- 处理极端小的概率值
- 避免浮点数精度问题
