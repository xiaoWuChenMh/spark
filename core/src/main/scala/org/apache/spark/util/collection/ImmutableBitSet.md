# ImmutableBitSet 源码分析

## 类的概述和定义

`ImmutableBitSet` 是一个不可变的位集合实现，继承自 `BitSet` 类。该类的核心设计理念是在构造函数中一次性初始化所有需要设置的位，然后禁止所有后续的修改操作，从而实现真正的不可变性。

**设计目标**：提供一个轻量级、线程安全的位集合实现，适用于需要固定位模式且不需要修改的场景。

## 构造函数参数说明

```scala
class ImmutableBitSet(val numBits: Int, val bitsToSet: Int*) extends BitSet(numBits)
```

### 参数详解
- **`numBits: Int`**：位集合的总容量（位数），决定了内部存储数组的大小
- **`bitsToSet: Int*`**：可变参数列表，指定在构造时需要设置为1的位索引

### 继承关系
- **父类**：`BitSet(numBits)` - 继承基础位集合功能
- **初始化**：在构造函数中调用父类构造函数设置初始容量

## 核心属性分析

### 继承属性
- **`words: Array[Long]`**：从父类继承的存储数组，每个long存储64位
- **`numWords: Int`**：从父类继承的数组长度

### 自定义属性
- **`numBits: Int`**：公开的只读属性，表示位集合容量
- **`bitsToSet: Seq[Int]`**：内部存储的要设置的位索引列表

## 主要方法分类和说明

### 初始化方法

#### 构造函数初始化块
```scala
{
    val bitsIterator = bitsToSet.iterator
    while (bitsIterator.hasNext) {
        super.set(bitsIterator.next)
    }
}
```

- **功能**：在对象构造时一次性设置所有指定的位
- **实现细节**：
  - 使用迭代器遍历 `bitsToSet` 参数
  - 调用父类的 `set` 方法设置每个位
  - 在对象完全构造前完成所有位设置

### 不可变性保护方法

#### `clear(): Unit` - 清除所有位
- **功能**：尝试清除所有位时抛出异常
- **异常信息**：`"mutable operation is not supported"`
- **设计意图**：防止修改已设置的位模式

#### `clearUntil(bitIndex: Int): Unit` - 清除到指定索引
- **功能**：尝试清除部分位时抛出异常
- **应用场景**：防止批量清除操作

#### `set(index: Int): Unit` - 设置单个位
- **功能**：尝试设置单个位时抛出异常
- **设计考虑**：即使设置未设置的位也不允许

#### `setUntil(bitIndex: Int): Unit` - 设置到指定索引
- **功能**：尝试批量设置位时抛出异常
- **一致性保证**：保持构造时的位模式不变

#### `unset(index: Int): Unit` - 取消设置位
- **功能**：尝试取消设置位时抛出异常
- **对称性设计**：与 `set` 方法对称的不可变保护

#### `union(other: BitSet): Unit` - 并集操作
- **功能**：尝试与其他位集合并集时抛出异常
- **设计原则**：不允许通过集合运算修改当前集合
