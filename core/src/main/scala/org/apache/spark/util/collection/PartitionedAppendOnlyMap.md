# PartitionedAppendOnlyMap 源码分析

## 类的概述和定义

`PartitionedAppendOnlyMap` 是一个实现了 `WritablePartitionedPairCollection` 接口的分区只追加映射实现。该类包装了一个内部映射，其中键为元组 `(分区ID, K)`，为Spark的Shuffle操作提供分区级别的键值对存储和管理功能。

**核心设计理念**：通过将分区ID与键组合的方式，在单个映射中实现分区数据的管理，同时保持只追加的特性，为外部排序器提供基础数据结构支持。

## 继承关系分析

```scala
class PartitionedAppendOnlyMap[K, V]
  extends SizeTrackingAppendOnlyMap[(Int, K), V] 
  with WritablePartitionedPairCollection[K, V]
```

### 父类继承
- **`SizeTrackingAppendOnlyMap[(Int, K), V]`**：继承大小跟踪的只追加映射功能
- **键类型**：`(Int, K)` - 分区ID和键的组合
- **值类型**：`V` - 任意值类型

### 接口实现
- **`WritablePartitionedPairCollection[K, V]`**：实现可写分区键值对集合接口
- **提供标准接口**：为外部排序器提供统一的访问接口

## 核心属性分析

### 继承属性
- **内部映射结构**：继承自 `SizeTrackingAppendOnlyMap` 的所有属性和方法
- **大小跟踪**：自动跟踪映射的大小用于内存管理
- **只追加特性**：支持插入和更新，但不支持删除

### 分区相关属性
- **隐式分区信息**：通过键的元组结构隐式包含分区ID
- **排序支持**：支持按分区和键进行排序

## 主要方法分类和说明

### 数据插入方法

#### `insert(partition: Int, key: K, value: V): Unit` - 插入分区键值对
- **功能**：向映射中插入指定分区的键值对
- **参数说明**：
  - `partition: Int`：分区ID
  - `key: K`：键
  - `value: V`：值
- **实现细节**：
  - 将分区ID和键组合为元组 `(partition, key)`
  - 调用父类的 `update` 方法进行插入/更新
  - 保持只追加映射的特性

### 迭代器方法

#### `partitionedDestructiveSortedIterator(keyComparator: Option[Comparator[K]]): Iterator[((Int, K), V)]` - 分区排序迭代器
- **功能**：返回按分区和键排序的破坏性迭代器
- **参数说明**：
  - `keyComparator: Option[Comparator[K]]`：可选的键比较器
- **排序策略**：
  - **有键比较器**：先按分区排序，再按键排序
  - **无键比较器**：只按分区排序
- **破坏性特性**：迭代后映射不可再使用
- **实现逻辑**：
  1. 根据是否提供键比较器选择适当的比较器
  2. 调用父类的 `destructiveSortedIterator` 方法
  3. 返回排序后的迭代器

- **元组键结构**：使用 `(Int, K)` 作为复合键
