# StratifiedSamplingUtils 类分析文档

## 类的概述和定义

`StratifiedSamplingUtils` 是Spark内部使用的一个分层采样工具类，专门用于实现`sampleByKey`方法的分层采样功能。该类被标记为`private[spark]`，是Spark内部使用的复杂采样工具。

该类包含三个主要组件：
- `StratifiedSamplingUtils` 对象：主要的分层采样方法实现
- `RandomDataGenerator` 类：统一的随机数据生成器
- `AcceptanceResult` 类：采样接受结果跟踪器

## 构造函数参数说明

由于`StratifiedSamplingUtils`是一个工具类对象（object），没有构造函数参数。

## 核心属性分析

### AcceptanceResult类属性
- **numItems**: `Long` - 处理的物品总数
- **numAccepted**: `Long` - 即时接受的物品数量
- **waitList**: `ArrayBuffer[Double]` - 等待列表，存储随机数值
- **acceptBound**: `Double` - 即时接受的上界
- **waitListBound**: `Double` - 等待列表的上界

### RandomDataGenerator类属性
- **uniform**: `XORShiftRandom` - 均匀分布随机数生成器
- **poissonCache**: `mutable.Map[Double, PoissonDistribution]` - 泊松分布缓存
- **poissonSeed**: `Long` - 泊松分布随机种子

## 主要方法分类和说明

### 核心采样方法

#### `getAcceptanceResults`
- **功能**: 统计每个分层的即时接受数量和生成等待列表
- **参数**:
  - `rdd: RDD[(K, V)]` - 输入键值对RDD
  - `withReplacement: Boolean` - 是否使用有放回采样
  - `fractions: Map[K, Double]` - 各分层的采样比例
  - `counts: Option[Map[K, Long]]` - 各分层的物品数量（可选）
  - `seed: Long` - 随机种子
- **返回值**: `mutable.Map[K, AcceptanceResult]` - 各分层的接受结果
- **实现原理**: 使用map-reduce模式聚合各分区的采样统计信息

#### `getSeqOp`
- **功能**: 定义分区内的序列操作函数，用于聚合采样统计
- **参数**:
  - `withReplacement: Boolean` - 采样方式
  - `fractions: Map[K, Double]` - 采样比例
  - `rng: RandomDataGenerator` - 随机数生成器
  - `counts: Option[Map[K, Long]]` - 分层计数
- **返回值**: 序列操作函数
- **算法细节**: 
  - 有放回采样：使用泊松分布计算接受和等待数量
  - 无放回采样：使用二项分布动态计算边界

#### `getCombOp`
- **功能**: 定义分区间的合并操作函数
- **返回值**: 合并操作函数
- **实现逻辑**: 合并不同分区的AcceptanceResult结果

### 阈值计算方法

#### `computeThresholdByKey`
- **功能**: 根据接受结果计算各分层的最终采样阈值
- **参数**:
  - `finalResult: Map[K, AcceptanceResult]` - 最终接受结果
  - `fractions: Map[K, Double]` - 采样比例
- **返回值**: `Map[K, Double]` - 各分层的采样阈值
- **算法流程**:
  1. 计算期望样本大小
  2. 根据即时接受数量确定需要从等待列表补充的数量
  3. 对等待列表排序并选择相应的阈值

### 采样函数生成方法

#### `getBernoulliSamplingFunction`
- **功能**: 生成无放回采样的伯努利采样函数
- **参数**:
  - `rdd: RDD[(K, V)]` - 输入RDD
  - `fractions: Map[K, Double]` - 采样比例
  - `exact: Boolean` - 是否需要精确样本大小
  - `seed: Long` - 随机种子
- **返回值**: 分区采样函数
- **特点**: 支持精确样本大小控制

#### `getPoissonSamplingFunction`
- **功能**: 生成有放回采样的泊松采样函数
- **参数**: 同伯努利采样函数
- **返回值**: 分区采样函数
- **实现差异**: 使用泊松分布生成样本副本数量

### 随机数生成方法

#### RandomDataGenerator类方法
- **reSeed**: 重新设置随机种子
- **nextPoisson**: 生成泊松分布随机数
- **nextUniform**: 生成均匀分布随机数

### 结果合并方法

#### AcceptanceResult.merge
- **功能**: 合并两个AcceptanceResult对象
- **实现**: 合并等待列表和计数统计

## 设计特点总结

### 1. 分层采样算法
- 支持精确样本大小控制
- 采用等待列表机制处理边界情况
- 结合即时接受和等待列表补充的策略

### 2. 双阶段采样设计
- **第一阶段**: 统计采样信息，计算阈值
- **第二阶段**: 使用计算得到的阈值进行实际采样
- 确保样本大小的精确性和可重复性

### 3. 随机数一致性保证
- 使用分区索引作为随机种子偏移量
- 确保相同分区生成相同的随机数序列
- 支持采样结果的可重复性

### 4. 内存效率优化
- 等待列表大小控制在O(√s)级别
- 使用高效的随机数生成器
- 避免不必要的数据复制

### 5. 算法多样性支持
- 同时支持有放回和无放回采样
- 基于不同的概率分布模型
- 适应不同的应用场景需求

## 配置参数说明

### 采样精度控制
- **exact**: `Boolean` - 是否启用精确样本大小模式
- **delta**: `Double = 5e-5` - 置信水平参数

### 随机种子管理
- **seed**: `Long` - 主随机种子
- **分区偏移**: `seed + partitionIndex` - 各分区的唯一种子

### 缓存配置
- **poissonCache**: 泊松分布对象缓存
- **避免重复创建分布对象，提高性能**
