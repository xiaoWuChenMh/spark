# OpenHashSet 源码分析

## 类的概述和定义

`OpenHashSet` 是一个简单、快速的哈希集合实现，专门为非空、只插入的使用场景优化。该类使用二次探测法解决哈希冲突，支持对四种基本类型（Long、Int、Double、Float）进行特殊化优化，比Java标准HashSet更快且内存开销更小。

**核心设计理念**：通过开放地址法和二次探测实现高效的哈希集合，作为优化哈希映射等高级数据结构的基础构建块。

## 构造函数参数说明

```scala
class OpenHashSet[@specialized(Long, Int, Double, Float) T: ClassTag](
    initialCapacity: Int,
    loadFactor: Double)
```

### 类型参数说明
- **`@specialized(Long, Int, Double, Float) T: ClassTag`**：支持特殊化的元素类型，需要 `ClassTag` 上下文绑定

### 构造函数重载
- **主构造函数**：`(initialCapacity: Int, loadFactor: Double)` - 指定初始容量和负载因子
- **简化构造函数**：`this(initialCapacity: Int) = this(initialCapacity, 0.7)` - 默认负载因子0.7
- **默认构造函数**：`this() = this(64)` - 默认容量64，负载因子0.7

### 前置条件验证
- **容量限制**：`initialCapacity <= OpenHashSet.MAX_CAPACITY`
- **容量非负**：`initialCapacity >= 0`
- **负载因子范围**：`0.0 < loadFactor < 1.0`

## 核心属性分析

### 容量和状态属性
- **`_capacity: Int`**：当前容量（2的幂次方）
- **`_mask: Int`**：位掩码，等于 `_capacity - 1`
- **`_size: Int`**：当前元素数量
- **`_growThreshold: Int`**：扩容阈值，计算公式：`loadFactor * _capacity`

### 数据存储属性
- **`_bitset: BitSet`**：标记已使用位置的位集合
- **`_data: Array[T]`**：存储实际元素的数组
- **`hasher: Hasher[T]`**：类型特定的哈希函数

### 特殊化优化属性
- **`@specialized`注解**：对四种基本类型进行特殊化处理
- **类型特定哈希器**：根据元素类型选择最优哈希函数

## 主要方法分类和说明

### 元素操作方法

#### `contains(k: T): Boolean` - 检查元素存在性
- **功能**：检查集合中是否包含指定元素
- **实现**：通过 `getPos(k) != INVALID_POS` 判断
- **性能**：O(1)平均时间复杂度

#### `add(k: T): Unit` - 添加元素
- **功能**：向集合中添加元素，必要时触发扩容
- **实现流程**：
  1. 调用 `addWithoutResize` 添加元素
  2. 调用 `rehashIfNeeded` 检查是否需要扩容
- **应用场景**：标准添加操作

#### `addWithoutResize(k: T): Int` - 不触发扩容的添加
- **功能**：添加元素但不触发扩容，返回位置信息
- **返回值语义**：
  - **位置掩码**：`retval & POSITION_MASK` 获取实际位置
  - **存在性掩码**：`(retval & NONEXISTENCE_MASK) == 0` 表示元素已存在
- **核心算法**：二次探测法解决哈希冲突

#### `union(other: OpenHashSet[T]): OpenHashSet[T]` - 并集操作
- **功能**：将另一个集合合并到当前集合
- **实现**：遍历另一个集合的元素并逐个添加
- **返回值**：返回当前集合以支持链式调用

### 位置查询方法

#### `getPos(k: T): Int` - 获取元素位置
- **功能**：返回元素在数组中的位置，不存在返回 `INVALID_POS`
- **算法**：使用二次探测法查找元素
- **终止条件**：找到元素或遇到空位置

#### `nextPos(fromPos: Int): Int` - 获取下一个已使用位置
- **功能**：从指定位置开始查找下一个已使用的位置
- **实现**：委托给 `_bitset.nextSetBit(fromPos)`
- **应用场景**：迭代器实现

### 数据访问方法

#### `getValue(pos: Int): T` - 获取指定位置的元素
- **功能**：返回指定位置的元素值
- **前提**：位置必须有效且已被使用

#### `getValueSafe(pos: Int): T` - 安全获取元素
- **功能**：带断言检查的元素获取
- **安全保证**：使用 `assert(_bitset.get(pos))` 验证位置有效性

### 迭代器方法

#### `iterator: Iterator[T]` - 返回迭代器
- **功能**：提供遍历集合中所有元素的能力
- **实现特点**：
  - 基于 `nextPos` 方法实现顺序遍历
  - 惰性计算，按需获取下一个元素
  - 支持标准的Scala迭代器接口

### 扩容和重新哈希方法

#### `rehashIfNeeded(k: T, allocateFunc: (Int) => Unit, moveFunc: (Int, Int) => Unit): Unit` - 检查并执行重新哈希
- **功能**：检查是否需要扩容，如果需要则执行重新哈希
- **触发条件**：`_size > _growThreshold`
- **回调机制**：通过回调函数支持扩展功能

#### `rehash(k: T, allocateFunc: (Int) => Unit, moveFunc: (Int, Int) => Unit): Unit` - 重新哈希
- **功能**：将集合容量翻倍并重新哈希所有元素
- **实现步骤**：
  1. 计算新容量并验证合法性
  2. 调用 `allocateFunc` 分配新数组
  3. 重新计算所有元素的哈希位置
  4. 调用 `moveFunc` 迁移数据
  5. 更新内部状态

## 内部算法详解

### 二次探测法（Quadratic Probing）

#### 算法原理
- **冲突解决**：当哈希冲突时，使用二次函数计算下一个探测位置
- **探测序列**：`pos, pos+1, pos+3, pos+6, ...`（增量：1, 2, 3, ...）
- **位置计算**：`newPos = (currentPos + delta) & _mask`

#### 数学保证
- **完全探测**：当容量为2的幂次方时，二次探测法能探测所有位置
- **避免循环**：使用质数增量避免探测序列形成循环

### 哈希函数优化

#### `hashcode(h: Int): Int` - 重新哈希函数
- **功能**：使用MurmurHash3对原始哈希值进行重新哈希
- **目的**：解决哈希函数在低位变化不足的问题
- **实现**：`Hashing.murmur3_32().hashInt(h).asInt()`

#### 类型特定哈希器
- **`LongHasher`**：使用 `(o ^ (o >>> 32)).toInt()`
- **`IntHasher`**：直接返回原值
- **`DoubleHasher`**：基于IEEE 754位表示计算哈希
- **`FloatHasher`**：使用 `floatToIntBits` 转换

### 位掩码操作

#### 位置掩码常量
- **`POSITION_MASK = (1 << 31) - 1`**：提取位置信息（低31位）
- **`NONEXISTENCE_MASK = 1 << 31`**：标记元素不存在（最高位）
- **`INVALID_POS = -1`**：无效位置常量

#### 掩码应用
- **位置提取**：`actualPos = returnValue & POSITION_MASK`
- **存在性判断**：`isNew = (returnValue & NONEXISTENCE_MASK) != 0`
