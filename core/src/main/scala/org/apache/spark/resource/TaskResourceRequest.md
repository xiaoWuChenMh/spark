# TaskResourceRequest 类分析

## 类的概述和定义

`TaskResourceRequest` 类是 Spark 资源管理系统中用于表示 Task 级别资源请求的核心类。它支持小数资源请求，允许配置多个任务共享同一个物理资源，从而实现资源的时分复用。

**类定义签名：**
```scala
@Evolving
@Since("3.1.0")
class TaskResourceRequest(val resourceName: String, val amount: Double) extends Serializable
```

**主要用途：**
- 定义单个 Task 的资源需求规格
- 支持小数资源，实现资源时分复用
- 与 `ResourceProfile` 配合使用，在阶段级别指定资源需求
- 提供流畅的 API 接口用于构建资源配置

**版本信息：**
- `@Since("3.1.0")`：从 Spark 3.1.0 版本开始提供
- `@Evolving`：标记为演进中的 API，未来可能有变更

## 构造函数参数说明

### 1. resourceName: String
- **作用**：资源类型的名称标识符
- **示例**："gpu"、"fpga"、"cpus"等
- **重要性**：唯一标识资源类型，用于匹配和验证
- **命名规范**：与 Spark 配置中的资源名称保持一致

### 2. amount: Double
- **作用**：Task 需要的资源数量，支持小数
- **有效范围**：必须 <= 0.5 或为整数
- **小数含义**：表示多个任务共享同一个资源地址
- **验证机制**：通过 assert 确保数值有效性

## 小数资源支持机制

### 小数资源的含义
**时分复用概念：**
- **amount = 0.25**：4个任务共享1个资源地址
- **amount = 0.5**：2个任务共享1个资源地址
- **amount = 1.0**：1个任务独占1个资源地址
- **amount = 2.0**：1个任务需要2个资源地址

### 资源调度实现
**调度器处理逻辑：**
1. **小数转换**：将小数转换为整数+部分数的形式
2. **地址分配**：为每个资源地址分配多个任务插槽
3. **时分复用**：多个任务按时间片共享物理资源

**示例：**
```scala
// amount = 0.25 的调度实现
val slotsPerAddress = 4  // 每个资源地址有4个插槽
val taskAmount = 1      // 每个任务需要1个插槽
// 4个任务可以共享同一个资源地址
```

### 使用限制
**有效值范围：**
- **小数资源**：必须 <= 0.5
- **整数资源**：必须是整数（amount % 1 == 0）
- **禁止范围**：0.5 < amount < 1.0 且不是整数

**设计考虑：**
- **简化调度**：避免复杂的调度算法
- **明确语义**：小数表示共享，整数表示独占
- **性能优化**：限制小数范围提高调度效率

## 使用场景示例

### 1. GPU 资源共享配置
```scala
// 4个任务共享1个GPU
val gpuRequest = new TaskResourceRequest("gpu", 0.25)
// 调度器会将同一个GPU分配给4个不同的任务
```

### 2. CPU 核心配置
```scala
// 每个任务需要2个CPU核心
val cpuRequest = new TaskResourceRequest("cpus", 2.0)
// 任务将独占2个CPU核心
```

### 3. 混合资源配置
```scala
// 复杂的资源需求组合
val requests = Map(
  "cpus" -> new TaskResourceRequest("cpus", 1.0),
  "gpu" -> new TaskResourceRequest("gpu", 0.5),  // 2个任务共享1个GPU
  "memory" -> new TaskResourceRequest("memory", 4096.0)
)
```

### 4. 与 ResourceProfile 集成
```scala
// 创建包含 Task 资源请求的 ResourceProfile
val profile = new ResourceProfileBuilder()
  .require(new ExecutorResourceRequests().cores(4).memory("8g"))
  .require(new TaskResourceRequests()
    .cpus(1)
    .resource("gpu", 0.25))  // 4个任务共享GPU
  .build()
```
