# MeanEvaluator 类分析文档

## 类的概述和定义

`MeanEvaluator` 是一个实现 `ApproximateEvaluator` 特质的类，专门用于近似均值计算。它基于统计学原理，使用t分布和正态分布来计算均值的置信区间，为大规模数据集的均值统计提供高效的近似解决方案。

该类位于 `org.apache.spark.partial` 包中，是Spark近似计算框架中数值统计的核心组件。

## 泛型参数说明

类使用特定的输入输出类型：

- **输入类型**：`StatCounter` - Spark的统计计数器，用于收集数值数据的统计信息
- **输出类型**：`BoundedDouble` - 包含均值、置信度和置信区间的近似结果

## 构造函数参数说明

构造函数接收两个关键参数：

- `totalOutputs: Int`：总任务数，表示需要处理的分区总数
- `confidence: Double`：置信度，取值范围[0,1]，表示结果的可信程度（通常为0.95或0.99）

## 核心属性分析

### 状态跟踪属性
- `private var outputsMerged = 0`：已合并的任务计数器
- `private val counter = new StatCounter()`：统计计数器，用于累积数值数据的统计信息

### StatCounter功能
StatCounter提供以下关键统计量：
- `count`：数据点数量
- `mean`：算术平均值
- `sum`：总和
- `variance`：方差
- `sampleVariance`：样本方差

## 主要方法分类和说明

### merge方法
```scala
override def merge(outputId: Int, taskResult: StatCounter): Unit
```

**功能**：合并单个任务的统计结果到当前评估状态

**执行步骤**：
1. 增加已合并任务计数器 `outputsMerged += 1`
2. 使用StatCounter的merge方法合并统计信息

**设计特点**：
- 利用StatCounter的内置合并功能，高效处理数值统计
- 支持增量式统计计算，避免重复计算

### currentResult方法
```scala
override def currentResult(): BoundedDouble
```

**功能**：根据当前统计状态计算并返回近似均值结果

**执行逻辑分层处理**：

1. **完全计算完成情况**：返回精确的均值结果
2. **未开始计算或零数据情况**：返回无限区间的零值结果
3. **单数据点情况**：返回无限区间的单点均值结果
4. **多数据点情况**：基于样本统计量计算置信区间

**核心计算逻辑**：
- 计算均值：`mean = counter.mean`
- 计算标准误差：`stdev = math.sqrt(counter.sampleVariance / counter.count)`
- 根据样本量选择分布模型：
  - 大样本（n > 100）：使用正态分布
  - 小样本：使用t分布
- 计算置信因子和置信区间

## 数学算法分析

### 统计分布选择

#### t分布应用（小样本）
- 适用于样本量较小的情况（n ≤ 100）
- 考虑样本量对估计精度的影响
- 使用自由度 `degreesOfFreedom = count - 1`

#### 正态分布近似（大样本）
- 当样本量足够大时（n > 100），t分布近似于正态分布
- 计算更高效，避免t分布的复杂计算
- 基于中心极限定理的合理性

### 置信区间计算

**标准误差公式**：
```
标准误差 = sqrt(样本方差 / 样本数量)
```

**置信区间公式**：
```
置信区间 = [均值 - 置信因子 × 标准误差, 均值 + 置信因子 × 标准误差]
```

**置信因子计算**：
- 使用逆累积概率函数计算分位数
- 对称区间使用 `(1 + confidence) / 2` 作为分位点
