# CountEvaluator 类分析文档

## 类的概述和定义

`CountEvaluator` 是一个实现 `ApproximateEvaluator` 特质的类，专门用于近似计数统计。它基于泊松分布理论，能够在大数据集的部分计算结果基础上，估算完整的计数结果并给出置信区间。

该类位于 `org.apache.spark.partial` 包中，是Spark近似计算框架中用于计数操作的核心组件。

## 构造函数参数说明

构造函数接收两个关键参数：

- `totalOutputs: Int`：总任务数，表示需要处理的分区总数
- `confidence: Double`：置信度，取值范围[0,1]，表示结果的可信程度（通常为0.95或0.99）

## 核心属性分析

### 状态跟踪属性
- `private var outputsMerged = 0`：已合并的任务计数器，记录已处理的分区数量
- `private var sum: Long = 0`：累计和，存储所有已处理分区的计数总和

### 统计计算属性
- `totalOutputs` 和 `confidence` 参数在对象生命周期内保持不变，用于指导计算过程

## 主要方法分类和说明

### merge方法
```scala
override def merge(outputId: Int, taskResult: Long): Unit
```

**功能**：合并单个任务的计算结果到当前评估状态

**执行步骤**：
1. 增加已合并任务计数器 `outputsMerged += 1`
2. 累加任务结果到总和 `sum += taskResult`

**设计特点**：
- 简单高效的状态更新，只维护必要的统计信息
- 忽略 `outputId` 参数，因为计数操作不依赖任务顺序

### currentResult方法
```scala
override def currentResult(): BoundedDouble
```

**功能**：根据当前状态计算并返回近似计数结果

**执行逻辑**：
1. **完全计算完成情况**：如果所有任务都完成（`outputsMerged == totalOutputs`），返回精确结果
2. **无数据或零和情况**：如果未处理任何任务或总和为零，返回零值结果
3. **部分计算情况**：使用泊松分布估算剩余数据的计数

**返回值说明**：
- 返回 `BoundedDouble` 对象，包含均值、置信度和置信区间

## 伴生对象和静态方法

### bound方法
```scala
def bound(confidence: Double, sum: Long, p: Double): BoundedDouble
```

**功能**：核心的统计计算方法，基于泊松分布理论计算置信区间

**数学原理**：
1. **数据采样率**：`p = outputsMerged / totalOutputs` 表示已处理数据的比例
2. **计数速率估计**：观测到的计数速率为 `sum / p`
3. **剩余数据分布**：剩余数据的计数服从泊松分布 `Poisson(sum*(1-p)/p)`
4. **置信区间计算**：使用泊松分布的分位数函数计算置信边界

**计算步骤**：
1. 创建泊松分布对象 `new PoissonDistribution(sum * (1 - p) / p)`
2. 计算置信区间下限：`dist.inverseCumulativeProbability((1 - confidence) / 2)`
3. 计算置信区间上限：`dist.inverseCumulativeProbability((1 + confidence) / 2)`
4. 构建最终结果：将观测值加到分布统计量上

- 妥善处理零计数和未开始计算的情况

- 提供合理的默认返回值

## 数学算法分析

### 泊松分布应用
泊松分布适用于描述单位时间内随机事件发生的次数，非常适合计数统计场景。

### 置信区间计算
使用 `(1-confidence)/2` 和 `(1+confidence)/2` 作为分位数点，确保置信区间的对称性。

### 均值估计
最终均值估计为 `sum + dist.getNumericalMean()`，结合观测值和期望值。

## 使用场景和最佳实践

### 适用场景
- 大数据集的近似计数操作（如RDD.count()）

## 配置参数说明

### 置信度参数
- `confidence`：控制结果的可靠性水平
- 值越高，置信区间越宽，结果越可靠但精度可能降低
- 典型值：0.90、0.95、0.99

### 任务数参数
- `totalOutputs`：影响采样率的计算
- 需要准确反映实际的数据分区数量
