# 读书笔记整理器

## 概述

本技能专门用于帮助用户按照高内聚低耦合原则和金字塔原理来系统化整理读书笔记。通过科学的分类方法和结构化思维，将零散的读书笔记转化为系统化的知识体系。

## 核心原则

### 高内聚低耦合原则
- **高内聚**：每个知识点单元内部逻辑紧密相关，功能单一明确
- **低耦合**：知识点之间保持独立性，减少相互依赖
- **模块化**：将复杂知识分解为可独立存在的知识点模块

### 金字塔原理
- **结论先行**：每个知识点单元以核心结论开头
- **自上而下**：从总体框架到具体细节的层次结构
- **逻辑分组**：按照MECE原则（相互独立，完全穷尽）进行分类
- **递进关系**：知识点之间建立清晰的逻辑递进关系

## 工作流程

### 1. 笔记输入与预处理
- 支持多种笔记格式：划线笔记、灵感笔记、总结笔记
- 提取核心知识点和关键概念
- 识别笔记之间的关联性和层次关系

### 2. 知识点识别与提取
- 分析笔记内容，识别独立的知识点单元
- 提取每个知识点的核心概念和关键信息
- 确定知识点的粒度和边界

### 3. 金字塔结构构建
- 建立总体框架和核心主题
- 按照逻辑层次组织知识点
- 创建从宏观到微观的知识体系

### 4. 分类与标签系统
- 基于内容主题建立分类体系
- 为每个知识点添加合适的标签
- 建立交叉引用和关联关系

### 5. 输出与呈现
- 生成结构化的读书笔记文档
- 提供多种输出格式选择
- 支持知识图谱可视化

## 使用示例

### 示例1：技术书籍笔记整理
**用户输入**："整理《设计模式》的读书笔记，包含创建型、结构型、行为型模式的笔记"

**处理流程**：
1. 识别设计模式的核心主题
2. 按照模式类型建立分类体系
3. 为每个模式创建独立的知识点单元
4. 建立模式之间的关联关系

### 示例2：文学类书籍笔记整理
**用户输入**："整理《红楼梦》的人物关系和主题分析笔记"

**处理流程**：
1. 建立人物关系图谱
2. 分析主要主题和次要主题
3. 按照情节发展组织知识点
4. 建立主题之间的逻辑关系

## 最佳实践

1. **保持简洁**：每个知识点尽量控制在300字以内
2. **明确边界**：确保知识点之间的界限清晰
3. **建立关联**：合理建立知识点之间的引用关系
4. **定期更新**：随着阅读深入不断优化知识结构
5. **注重实用**：关注知识点的实际应用价值
