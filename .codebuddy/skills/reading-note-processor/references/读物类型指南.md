# 读物类型判断指南

## 输出格式标准

```json
{
  "core_type": "核心类型，必填，取值：'实用型'、'理论型'、'想象文学'",
  "secondary_types": ["必填，数组格式，可包含多个类型，按重要性排序"],
  "structure_type": "必填，取值：'强结构'、'弱结构'",
  "hybrid_flag": "必填，布尔值，表示是否为混合类型",
  "confidence": "必填，0-1之间的浮点数，表示判断置信度"
}
```

**secondary_types 取值范围：**
- 想象文学：["小说"]、["诗歌"]、["戏剧"]
- 理论型：["历史类"]、["科学类"]、["哲学类"]、["数学类"]、["社会科学类"]、["心理学类"]、["脑科学类"]、["医学理论类"]、["理论综合类"]
- 实用型：["商业管理类"]、["技能训练类"]、["工具参考类"]、["健康生活类"]、["教育培训类"]、["个人发展类"]、["技术应用类"]、["临床医学类"]、["亲密关系类"]、["实用综合类"]

## 阶段1：核心类型识别

### 分析维度

#### 标题关键词分析
```
实用型触发词 = ["如何", "指南", "手册", "技巧", "方法", "实操", "实战", "步骤", "提升", "改变", "训练", "养成", "操作", "应用"]
理论型触发词 = ["原理", "本质", "导论", "概论", "哲学", "研究", "理论", "分析", "思考", "批判", "探讨", "论证", "历史", "科学", "数学"]
想象文学触发词 = ["小说", "诗集", "戏剧", "故事", "传", "记", "演义", "童话", "寓言", "散文", "诗歌", "剧本"]
```

#### 前言/简介语义分析
- **实用型特征**：出现"教会读者"、"步骤"、"方法"、"应用"、"效果"、"实践"、"操作"、"建议"、"应该"
- **理论型特征**：出现"探讨"、"研究"、"分析"、"论证"、"解释"、"证明"、"阐述"、"理解"
- **想象文学特征**：出现"故事"、"情节"、"人物"、"虚构"、"情感"、"想象"、"创作"、"叙事"

### 决策逻辑

```
步骤1：检查是否为想象文学
    如果标题包含想象文学触发词 AND (前言包含想象文学特征 OR 章节抽样为叙事性内容)
    则标记为"想象文学"，进入阶段2-想象文学分类

步骤2：检查是否为实用型
    如果(标题包含实用型触发词 > 理论型触发词) OR (前言实用特征词频 > 理论特征词频)
    则标记为"实用型"，进入阶段2-实用型分析

步骤3：默认为理论型
    进入阶段2-理论型分类
```

## 阶段2：细化分类识别

### 分支A：想象文学分类
```
IF 标题或内容包含明显体裁标识：
   - 包含"诗"、"词"、"歌"、"赋"、"韵" → 诗歌
   - 包含"第X幕"、"场"、"台词"、"对白"、"舞台" → 戏剧
   - 其他叙事性内容 → 小说
ELSE:
   根据抽样内容判断：
   - 分行书写，有韵律 → 诗歌
   - 对话形式，分场景 → 戏剧
   - 连续叙事，有情节 → 小说
```

### 分支B：理论型分类

#### 领域关键词检测
1. **历史类检测**：
   - 关键词：["世纪", "年代", "公元前", "王朝", "历史", "古代", "近代", "现代", "事件", "时期"]
   - 时间序列特征：章节按时间顺序排列
   
2. **科学类检测**：
   - 关键词：["实验", "数据", "观测", "验证", "定律", "公式", "定理", "证明", "物理", "化学", "生物", "自然"]
   - 方法论特征：强调可重复性和实证
   
3. **哲学类检测**：
   - 关键词：["存在", "意识", "道德", "逻辑", "真理", "形而上学", "认识", "价值", "伦理", "美学"]
   - 思辨特征：大量使用逻辑论证和概念分析
   
4. **数学类检测**：
   - 关键词：["证明", "公理", "推导", "算式", "集合", "函数", "方程", "几何", "代数", "统计"]
   - 形式化特征：高度抽象和符号化
   
5. **社会科学类检测**：
   - 关键词：["社会", "经济", "政治", "文化", "人类", "组织", "制度", "行为"]

6. **心理学类检测**：
   - 关键词：["心理", "意识", "认知", "行为", "情绪", "人格", "动机", "感知", "记忆", "思维", "学习", "发展"]
   - 特征：研究心理过程、行为和心理机制
   
7. **脑科学类检测**：
   - 关键词：["大脑", "神经", "神经元", "脑区", "认知神经", "脑功能", "神经递质", "神经网络", "脑成像", "意识机制"]
   - 特征：研究大脑结构和功能与认知、行为的关系
   
8. **医学理论类检测**：
   - 关键词：["病理", "生理", "解剖", "药理", "免疫", "遗传", "分子医学", "疾病机制", "诊断原理", "治疗理论"]
   - 特征：研究医学基础理论和疾病发生发展机制

#### 领域分配规则
- 计算各领域关键词出现频率
- 选择频率最高的前2个领域作为二级分类
- 如果最高频率 < 总关键词的40%，标记为"理论综合类"

### 分支C：实用型分类

#### 领域检测
1. **商业管理类**：
   - 关键词：["管理", "领导", "商业", "市场", "营销", "战略", "创业", "投资", "财务", "组织", "运营"]
   - 特征：关注组织运营、商业策略、管理方法
   
2. **技能训练类**：
   - 关键词：["训练", "练习", "技能", "技巧", "方法", "操作", "实操", "掌握", "熟练", "实践"]
   - 特征：强调通过练习掌握具体技能，包含大量操作步骤和训练方法
   
3. **工具参考类**：
   - 关键词：["手册", "指南", "参考", "查询", "字典", "百科", "速查", "索引", "目录", "规范"]
   - 特征：提供快速查询和参考信息，结构性强，便于查找
   
4. **健康生活类**：
   - 关键词：["健身", "饮食", "健康", "养生", "心理", "家庭", "关系", "沟通", "时间管理", "睡眠", "运动"]
   - 特征：关注个人身心健康和生活质量提升
   
5. **教育培训类**：
   - 关键词：["学习", "教育", "教学", "记忆", "阅读", "写作", "考试", "训练", "课程", "培训"]
   - 特征：专注于学习方法和教育理论
   
6. **个人发展类**：
   - 关键词：["成长", "发展", "提升", "改变", "习惯", "目标", "规划", "效率", "成功", "突破"]
   - 特征：关注个人能力提升和职业发展
   
7. **技术应用类**：
   - 关键词：["编程", "代码", "开发", "设计", "制作", "技术", "软件", "硬件", "工程", "应用", "实现"]
   - 特征：强调技术原理的实际应用和实现

8. **临床医学类**：
   - 关键词：["诊断", "治疗", "手术", "临床", "病例", "症状", "检查", "药物", "康复", "预防", "指南", "临床路径"]
   - 特征：提供临床实践指导和具体诊疗方法
   
9. **亲密关系类**：
   - 关键词：["爱情", "恋爱", "婚姻", "关系", "亲密", "情感", "约会", "沟通", "冲突", "吸引力", "伴侣", "相处"]
   - 特征：关注亲密关系建立、维护和改善的实用方法

#### 领域分配
- 选择频率最高的1-2个领域作为二级分类
- 如果没有明显领域倾向，标记为"实用综合类"

## 阶段3：混合类型处理

### 混合类型识别条件
1. **多领域混合**：理论型或实用型中检测到多个领域且频率相近（最高频率 < 2 × 第二高频率）
2. **理论-实用混合**：同时满足：
   - 实用型得分 > 0.3 AND 理论型得分 > 0.3
   - 且两者得分差 < 0.2

### 混合类型标记规则
- 在secondary_types中列出所有相关类型
- 按频率从高到低排序
- hybrid_flag设置为true

## 置信度计算

```
基础置信度 = 0.7

# 加分项
IF 标题特征明显 +0.1
IF 前言特征明显 +0.15
IF 目录结构清晰 +0.05
IF 抽样内容支持判断 +0.1

# 减分项
IF 信息不足（只有标题） -0.2
IF 类型特征冲突 -0.15
IF 领域特征模糊 -0.1

# 最终置信度 = 基础置信度 + 加分项 - 减分项
# 限制在0.5-0.95之间
```

## 组织结构分析

### 目录结构分析算法

#### 强结构识别
- **层递型**：章节标题显示递进关系（如"基础→进阶→高级"、"概念→原理→应用"）
- **总分型**：章节为平行结构，共同支持总标题（如多个"XX的方面/方法"）
- **时序型**：章节按时间顺序排列（含明显时间标识）

#### 弱结构识别
- **文集型**：章节独立性高，无明显逻辑联系
- **词典型**：按字母/笔画/主题词排列

#### 结构评分
```
结构强度 = (章节间关联度 + 逻辑顺序明显度) / 2
IF 结构强度 > 0.6 THEN 标记为"强结构"
ELSE 标记为"弱结构"
```

## 处理策略映射

### 理论型读物处理策略
- **核心策略**：提取核心概念和理论框架
- **关注重点**：理论的应用边界和限制条件
- **逻辑骨架**：树状分类、因果解释、道-法-术-器

### 实用型读物处理策略
- **核心策略**：提取核心方法和操作流程
- **关注重点**：方法的适用场景和效果
- **逻辑骨架**：流程序列、问题-解决方案、2W1H

### 想象文学处理策略
- **核心策略**：提取核心主题和艺术手法
- **关注重点**：作品的社会文化背景和情感表达
- **逻辑骨架**：时间线、主题-手法-意义
