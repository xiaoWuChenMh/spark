# 逻辑骨架框架库

## 框架类型总览

| 框架类型 | 核心逻辑要素 | 推荐应用范围（读物类型） | 来源参考 |
| :--- | :--- | :--- | :--- |
| **树状分类 (Taxonomy)** | 层级化、分类元素 | 科学类、生物学、体系化理论 | 林奈分类法 |
| **因果解释 (Causal)** | 原因 -> 结果 -> 影响 | 社会科学、心理学、历史背景分析 | 因果推断理论 |
| **流程与序列 (Process)** | 步骤1 -> 2 -> 3 | 操作指南、工具书、实用型手册 | 流程管理理论 |
| **论点/案例 (Argument)** | 观点 + 证据 + 结论 | 政治、经济、法律、论说性作品 | 逻辑学、论证理论 |
| **道-法-术-器** | 底层规律 -> 方法论 -> 技巧 -> 工具 | 深度技能学习、个人成长、职业进阶 | 中国传统智慧 |
| **5W1H深度分析** | 是什么、为什么、怎么做、何时、何地、谁 | 全面系统分析、复杂概念拆解 | 新闻学、系统分析 |
| **2W1H快速理解** | 是什么、为什么、怎么做 | 快速入门、概念速览、时间有限场景 | 快速学习理论 |
| **增强/调节回路** | 驱动力、阻碍力、反馈 | 商业策略、系统动力学、学习动机 | 系统思考理论 |

## 详细框架描述

### 1. 树状分类框架 (Taxonomy)
**核心特征：**
- 严格的层级结构（父类-子类关系）
- 互斥且完备的分类体系
- 明确的分类标准和边界

**适用读物：**
- 生物学分类学著作
- 图书馆分类系统
- 知识体系构建类书籍
- 任何需要系统分类的内容

**判断标准：**
- 内容是否强调分类和层级？
- 是否有明确的分类标准？
- 分类是否互斥且完备？

### 2. 因果解释框架 (Causal)
**核心特征：**
- 强调因果关系链
- 包含因果机制和中介变量
- 考虑多重因果和交互作用

**适用读物：**
- 社会科学研究
- 心理学分析
- 历史事件解读
- 政策效果评估

**判断标准：**
- 是否解释"为什么"发生？
- 是否有明确的因果机制？
- 是否考虑反事实推理？

### 3. 流程与序列框架 (Process)
**核心特征：**
- 明确的步骤顺序
- 每个步骤的输入输出
- 时间依赖性和前后关系

**适用读物：**
- 操作手册和指南
- 项目管理书籍
- 生产流程说明
- 任何需要按步骤执行的内容

**判断标准：**
- 是否有明确的先后顺序？
- 步骤之间是否有依赖关系？
- 是否强调时间线？

### 4. 论点/案例框架 (Argument)
**核心特征：**
- 明确的论点陈述
- 充分的证据支持
- 逻辑严密的推理过程

**适用读物：**
- 法律文书和辩论
- 学术论文
- 政策建议书
- 任何需要说服他人的内容

**判断标准：**
- 是否有明确的立场或观点？
- 是否有证据支持？
- 是否有反驳对立观点的内容？

### 5. 道-法-术-器框架
**核心特征：**
- 四个层次的递进关系
- 从抽象到具体的转化
- 理论与实践的结合

**适用读物：**
- 深度技能学习书籍
- 个人成长类读物
- 哲学思想著作
- 任何需要深度理解的内容

**判断标准：**
- 是否包含原理、方法、技巧、工具四个层次？
- 是否强调从理论到实践的转化？
- 是否关注内在规律和外在表现？

### 6. 5W1H深度分析框架
**核心特征：**
- 全面的六个维度分析
- 系统性和完整性
- 适合复杂问题的拆解

**适用读物：**
- 复杂系统分析
- 深度研究报告
- 战略规划文档
- 需要全面理解的内容

**判断标准：**
- 是否需要全面系统的分析？
- 问题复杂度是否较高？
- 是否有充足的时间进行深度思考？

### 7. 2W1H快速理解框架
**核心特征：**
- 精简的三个核心问题
- 快速抓住要点
- 适合时间有限的场景

**适用读物：**
- 快速入门指南
- 概念速览材料
- 时间紧迫的学习任务
- 需要快速掌握的内容

**判断标准：**
- 是否需要快速理解核心概念？
- 时间是否有限？
- 是否只需要掌握基本要点？

### 8. 增强/调节回路框架
**核心特征：**
- 识别正反馈和负反馈
- 分析系统动态平衡
- 理解系统自我调节机制

**适用读物：**
- 系统动力学研究
- 商业生态系统分析
- 学习动机研究
- 任何涉及反馈机制的内容

**判断标准：**
- 是否涉及反馈机制？
- 是否有自我调节的描述？
- 是否强调动态平衡？

## 新增补充框架

### 9. 问题-解决方案框架 (Problem-Solution)
**核心特征：**
- 明确的问题定义
- 针对性的解决方案
- 效果评估和改进

**适用读物：**
- 问题解决类书籍
- 创新思维训练
- 故障排除指南

### 10. 比较分析框架 (Comparative Analysis)
**核心特征：**
- 多方案对比
- 优劣分析
- 适用场景比较

**适用读物：**
- 产品评测
- 方案选择指南
- 决策分析材料

### 11. 时间线框架 (Timeline)
**核心特征：**
- 时间顺序排列
- 关键节点标记
- 发展趋势分析

**适用读物：**
- 历史事件记录
- 项目进度跟踪
- 个人发展历程

### 12. 空间结构框架 (Spatial Structure)
**核心特征：**
- 空间关系描述
- 组成部分分析
- 功能区域划分

**适用读物：**
- 建筑设计说明
- 地理空间分析
- 组织结构描述

## 框架选择判断标准

### 一级判断：读物类型匹配
1. **理论性读物** → 树状分类、因果解释、道-法-术-器
2. **实用性读物** → 流程序列、问题-解决方案、2W1H
3. **分析性读物** → 论点案例、5W1H、比较分析
4. **叙事性读物** → 时间线、因果解释
5. **描述性读物** → 空间结构、树状分类

### 二级判断：内容复杂度
- **高复杂度**：5W1H、道-法-术-器、增强调节回路
- **中复杂度**：因果解释、论点案例、比较分析
- **低复杂度**：2W1H、流程序列、问题-解决方案

### 三级判断：使用场景
- **深度学习**：选择全面系统的框架（5W1H、道-法-术-器）
- **快速应用**：选择简洁高效的框架（2W1H、流程序列）
- **分析研究**：选择分析性强的框架（因果解释、论点案例）
- **记忆理解**：选择结构清晰的框架（树状分类、时间线）

### 冲突解决原则
1. **主导性原则**：选择与读物主要特征最匹配的框架
2. **实用性原则**：优先考虑实际应用需求
3. **完整性原则**：确保框架能够覆盖主要内容
4. **效率原则**：在效果相当的情况下选择更简洁的框架

## 框架组合使用指南

### 主框架 + 辅助框架
- 主要使用一个核心框架
- 在特定部分使用辅助框架补充
- 例如：主框架用5W1H，在"怎么做"部分用流程序列框架

### 分层使用
- 宏观层面使用一个框架
- 微观层面使用另一个框架
- 例如：整体用道-法-术-器，具体方法用2W1H

### 交替使用
- 根据不同章节特点选择不同框架
- 保持整体逻辑的一致性
- 在框架转换处做好过渡说明

## 实践应用示例

### 示例1：商业策略书籍
**推荐框架**：增强/调节回路 + 问题-解决方案
**理由**：商业策略涉及市场反馈和问题解决

### 示例2：心理学研究
**推荐框架**：因果解释 + 比较分析
**理由**：心理学强调因果关系和实验对比

### 示例3：编程教程
**推荐框架**：流程序列 + 2W1H
**理由**：编程需要步骤指导和快速理解
