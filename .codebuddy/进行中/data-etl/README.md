# 数仓数据加工技能 (Date ETL Skill)

## 概述

数仓数据加工技能是一个专门用于数仓数据处理的综合技能，采用分层架构（DWD、DIM、DWS、ADS）和工作流决策树，能够根据用户请求智能选择合适的工作流执行数据加工任务。

## 技能结构

```
.data-warehouse-processing/
├── SKILL.md                        # 技能主文档
├── README.md                       # 本文件
├── table_category/                 # 数据分类目录（知识的一种）
│   └── datong_dwd.md               # 大同dwd层数据
├── workfolw/                       # 数据加工流程目录
│   └── datong_dwd_workflow.md      # 大同dwd层数据加工流程
```
