# 数仓数据加工技能

## 概述

本技能为数据仓库加工提供专业指导，基于分层架构(dwd、dim、dws、ads)、数据分类类型(事实表、维度表、聚合表、应用表)和具体操作步骤(字段增加、数据转换、聚合计算等)来选择合适的执行工作流。技能包含表结构信息获取、Python加工逻辑指导和分层处理决策树。

## 分层架构决策树

当处理数仓数据加工任务时，首先确定目标表所属的层级：

### 1. DWD层 (明细数据层)
- **特征**：最细粒度的事实数据，保留原始业务细节
- **典型操作**：数据清洗、字段映射、格式转换、数据关联
- **触发场景**：用户提到"原始数据"、"明细表"、"事实表"、"清洗"等关键词
- **工作流选择**：优先选择数据清洗和ETL处理工作流

### 2. DIM层 (维度数据层)
- **特征**：描述性数据，业务实体属性
- **典型操作**：维度属性扩展、缓慢变化维度处理、代码映射
- **触发场景**：用户提到"维度表"、"属性表"、"代码表"、"字典表"等关键词
- **工作流选择**：优先选择维度建模和属性管理工作流

### 3. DWS层 (汇总数据层)
- **特征**：轻度汇总数据，按主题域聚合
- **典型操作**：按维度聚合、指标计算、时间窗口计算
- **触发场景**：用户提到"汇总表"、"聚合表"、"主题表"、"指标计算"等关键词
- **工作流选择**：优先选择聚合计算和指标加工工作流

### 4. ADS层 (应用数据层)
- **特征**：面向应用的宽表，高度汇总
- **典型操作**：多表关联、宽表构建、应用指标计算
- **触发场景**：用户提到"应用表"、"宽表"、"报表表"、"业务指标"等关键词
- **工作流选择**：优先选择宽表构建和业务指标工作流

## 数据分类类型识别

### 事实表
- **识别特征**：包含度量值、交易数据、可累加指标
- **加工重点**：确保数据完整性、准确性，处理空值和异常值
- **Python模式**：数据验证 + 异常处理 + 指标计算

### 维度表
- **识别特征**：描述性属性、代码映射、层次结构
- **加工重点**：属性一致性、代码标准化、缓慢变化处理
- **Python模式**：字典映射 + 属性标准化 + 历史版本管理

### 聚合表
- **识别特征**：汇总指标、分组统计、预计算结果
- **加工重点**：聚合逻辑正确性、计算性能优化
- **Python模式**：分组聚合 + 窗口计算 + 性能优化

### 应用表
- **识别特征**：宽表结构、业务指标、多源整合
- **加工重点**：数据整合一致性、业务逻辑实现
- **Python模式**：多表关联 + 指标衍生 + 业务逻辑封装

## 操作步骤工作流选择

### 字段增加操作
1. **识别字段类型**：维度属性、度量指标、计算字段、关联字段
2. **确定数据来源**：原始字段计算、外部表关联、代码映射
3. **选择加工逻辑**：
   - 简单计算：直接使用现有字段计算
   - 复杂逻辑：需要业务规则和条件判断
   - 外部关联：需要表连接和匹配逻辑
4. **验证字段合理性**：数据类型、取值范围、业务含义

### 数据转换操作
1. **识别转换类型**：格式转换、代码映射、单位换算、数据脱敏
2. **确定转换规则**：一对一映射、多对一映射、条件转换
3. **选择转换方法**：字典映射、正则表达式、自定义函数
4. **验证转换结果**：数据一致性、完整性检查

### 聚合计算操作
1. **识别聚合维度**：时间维度、业务维度、组合维度
2. **确定聚合指标**：计数、求和、平均值、最大值、最小值
3. **选择聚合方法**：简单分组、窗口函数、分层聚合
4. **验证计算结果**：数据准确性、逻辑正确性

## 知识获取与使用

### 表结构信息获取
当需要了解表结构时：
1. 询问用户提供表结构描述
2. 如果用户没有提供，请求表名和关键字段信息
3. 基于分层架构推断可能的字段结构

### Python加工逻辑
根据操作类型提供Python代码模式：
1. **DWD层清洗**：数据验证、格式转换、异常处理
2. **DIM层扩展**：属性标准化、代码映射、历史追踪
3. **DWS层聚合**：分组计算、窗口函数、性能优化
4. **ADS层整合**：多表关联、指标衍生、业务封装
